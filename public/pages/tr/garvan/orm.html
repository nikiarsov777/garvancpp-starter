ORM / Query Builder

Garvan'ın veri katmanının iki parçası vardır. Builder veritabanı başına bir Grammar aracılığıyla parametreli statement'ler üretir, sonra bunları bir DbClient aracılığıyla çalıştırır. OModel, model nesnelerinizin bu builder metodlarını doğrudan sergilemek için genişlettiği temel sınıftır.

Builder

Builder akıcı bir API kullanır. Her çağrı builder'ı döndürür, böylece koşulları zincirleyebilirsiniz:

Builder qb(dbClient, grammar, "users",
           /*public*/{"id","name","email"},
           /*private*/{"password"});

auto rows = qb
    .where("active", "=", "1")
    ->where("role", "=", "admin")
    ->get();

Sorgu uçtan uca parametreli — kullanıcı tarafından sağlanan değerler string birleştirme yerine yerel PreparedStatement binding üzerinden akar. SQL injection söz konusu değil.

Diğer shortcut'lar: first(), firstOrFail(), find(id), findOrFail(id), artı insert(json), update(json) ve remove().

OModel

Modeller ORM::OModel'i genişletir ve tablo adlarını ile sütun listelerini bildirir:

class User : public ORM::OModel
{
public:
    User() {
        table          = "users";
        primaryKey     = "id";
        public_columns  = {"id", "name", "email"};
        private_columns = {"password"};
    }
};

Veritabanı başına Grammar'lar

Her sürücü, doğru lehçeyi nasıl yayacağını bilen bir Grammar alt sınıfı sağlar:

  • PostgresGrammar
  • MysqlGrammar
  • SqliteGrammar
  • MonetdbGrammar
  • MongoGrammar — SQL yerine Mongo komutları üretir.

Doğru grammar DATABASE_TYPE'dan otomatik olarak seçilir. Normalde bu sınıflara doğrudan dokunmayacaksınız.
