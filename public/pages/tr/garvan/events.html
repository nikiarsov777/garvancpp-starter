Olaylar

Olaylar, uygulamanızın bir bölümünün kimin dinlediğini bilmeden diğerlerini bilgilendirmesini sağlar. Bir olayı bir kez fire edin; her kayıtlı listener çalışır — senkron, kayıt sırasına göre, aynı thread'te.

Event API

Bir olay Garvan::Event'ten türeyen küçük bir value sınıfıdır:

// app/events/UserRegistered.h
#include "events/Event.h"
#include "tools/JsonValue.h"

namespace AppEvents {

class UserRegistered : public Garvan::Event
{
public:
    UserRegistered() = default;
    UserRegistered(int id, std::string mail, std::string person)
        : user_id(id), email(std::move(mail)), name(std::move(person)) {}

    std::string eventName() const override { return "UserRegistered"; }

    Garvan::JsonValue payload() const override;
    static std::unique_ptr<Garvan::Event>
        fromPayload(const Garvan::JsonValue& p);

    int         user_id{};
    std::string email;
    std::string name;
};

} // namespace AppEvents

Bir listener yazma

Garvan::Listener<YourEvent>'ten türetin ve handle()'ı implement edin:

// app/listeners/SendWelcomeEmailListener.h
#include "events/Listener.h"
#include "../events/UserRegistered.h"

class SendWelcomeEmailListener
    : public Garvan::Listener<AppEvents::UserRegistered>
{
public:
    void handle(const AppEvents::UserRegistered& event) override;
};

Listener gövdesi her şey yapabilir — veritabanına yazma, bir servisi çağırma veya bir job dispatch etme (aynen SendWelcomeEmailListener'ın yaptığı gibi, forward AppJobs::SendTestMail'e).

Event fire etme

#include "events/EventDispatcher.h"
#include "app/events/UserRegistered.h"

Garvan::EventDispatcher::fire(
    std::make_unique<AppEvents::UserRegistered>(42, "u@x.com", "Ada"));

Listener'lar aynı thread'te senkron çağrılır; biri exception atarsa sonrakiler yine de çalışır ve fire() ilk exception'ı sonda tekrar fırlatır.

Service provider'da kayıt

EventServiceProvider::register_() içinde iki kayıt:

// app/providers/EventServiceProvider.cpp
Garvan::EventDispatcher::listen<AppEvents::UserRegistered,
                                LogRegistrationListener>();
Garvan::EventDispatcher::listen<AppEvents::UserRegistered,
                                SendWelcomeEmailListener>();

// Opsiyonel: event factory'yi admin API `event:fire` için kaydeder
GARVAN_REGISTER_EVENT(AppEvents::UserRegistered);

GARVAN_REGISTER_JOB'un aksine, event macro'su tamam: dispatch anahtarı runtime'da eventName()'den alınır, stringified tip isminden değil.

Provider'lar main.cpp:56-60'ta sabit bir sırada boot olur — önce AppServiceProvider (queue driver'ları), sonra JobServiceProvider, ardından EventServiceProvider. Listener'lar boot sırasında güvenle job dispatch edebilir çünkü job'lar zaten kayıtlıdır.

Örnek: UserRegistered chain

GET /api/events/user-registered?email=...&name=...&id=...
  → EventDispatcher::fire(UserRegistered)
      → LogRegistrationListener::handle()      (sync log satırı)
      → SendWelcomeEmailListener::handle()
           → JobDispatcher::dispatch(SendTestMail)
                → SyncDriver (inline)
                     → SendTestMail::handle()  (libcurl SMTP send)
