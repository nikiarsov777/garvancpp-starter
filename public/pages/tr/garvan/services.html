Servisler

Servisler controller'lar ile modeller arasında oturur. Hiçbirine ait olmayan iş mantığını tutarlar — doğrulama, çoklu-tablo operasyonları, harici API çağrıları.

BaseService

Temel sınıf BaseContoller'ı yansıtır ama tüm metodlar virtual:

class BaseService : public Helper
{
public:
    virtual json index();
    virtual json create(json model);
    json         create(const crow::request &req); // kolaylık: body'yi sizin için parse eder
    virtual json read(string id);
    virtual json update(json model);
    virtual void erease();
    virtual json getById(string id);
};

Bir controller'da servis kullanma

Servisi controller metodunun içinde instantiate edin veya constructor üzerinden inject edin:

json PostController::index()
{
    PostService svc;
    auto posts = svc.index();

    // post-processing: private alanları gizle, pagination metadata ekle, vs.
    json out;
    out["data"]  = posts;
    out["count"] = posts.size();
    return out;
}

Servis katmanı ayrıca testi kolaylaştırır — controller'lar ince shim'lere dönüşür ve servisler HTTP sunucusunu ayağa kaldırmadan çalıştırılabilir.
