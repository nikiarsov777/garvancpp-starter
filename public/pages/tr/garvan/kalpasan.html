Kalpasan CLI

kalpasan projenin komut satırı arkadaşıdır. Model, controller ve service scaffold eder, migration ve seeder çalıştırır ve file watching ile bir development sunucusu başlatır.

Kurulum

Binary vendors/Garvan/kalpasan'da yaşar. Proje kökündeki bir symlink çağırmayı kolaylaştırır:

ln -s vendors/Garvan/kalpasan kalpasan
./kalpasan --help

Scaffolding ve DB komutları

./kalpasan make:model User           # scaffold app/models/User.{h,cpp}
./kalpasan make:controller User      # scaffold app/controllers/UserController.{h,cpp}
./kalpasan make:service User         # scaffold app/services/UserService.{h,cpp}
./kalpasan make:migration create_users

./kalpasan db:migrate                # garvan-migrate up'a delege eder
./kalpasan db:rollback               # garvan-migrate down'a delege eder
./kalpasan db:seed                   # db/seeders/ dosyalarını çalıştırır

./kalpasan serve --watch             # .cpp/.h değişince rebuild + restart

Tüm komutlar aktif .env'e saygı gösterir, böylece doğru DB'yi hedeflerler.

Runtime verbs (jobs, events, config)

Bu verb'ler çalışan uygulamayla HTTP (libcurl) üzerinden konuşur. .env'den KALPASAN_ADMIN_URL (default http://127.0.0.1:9090) ve KALPASAN_ADMIN_TOKEN okurlar, sonra routes/AdminRoute.cpp'deki bearer-guarded admin endpoint'lerine giderler.

./kalpasan job:list                                # GET /api/admin/jobs
./kalpasan job:dispatch SendTestMail \              # POST /api/admin/jobs/dispatch
    --field to=you@x.com \
    --field subject="Hi" \
    --field body="<h1>Hello</h1>"

./kalpasan event:list                              # GET /api/admin/events
./kalpasan event:fire UserRegistered \             # POST /api/admin/events/fire
    --field id=42 \
    --field email=you@x.com \
    --field name="Ada"

./kalpasan route:list                              # HTTP route'ları yazdır
./kalpasan config:show                             # dump .env
./kalpasan config:get MAIL_HOST                    # bir anahtarı oku
./kalpasan config:set MAIL_HOST smtp.new.com       # bir anahtarı yeniden yaz
./kalpasan config:key:generate                     # yeni APP_KEY (base64 32-byte)
Admin auth guard

AdminRoute üç koşul sağlanmadıkça isteği reddeder: .env'de KALPASAN_ADMIN_TOKEN boş değil, istek loopback'ten (127.0.0.1 veya ::1) geliyor ve Authorization: Bearer <token> header'ı uyuyor. Aksi halde 401 / 403 / 503 durumlu JSON error döner (bkz. routes/AdminRoute.cpp:55-82).
