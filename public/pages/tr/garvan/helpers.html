Yardımcılar

Üç küçük yardımcı sınıf vendors/Garvan/include/tools/ altında yaşar. Controller ve service yazarken onlarla karşılaşacaksınız.

Helper

Helper sınıfı hem BaseContoller'ın hem de BaseService'ın temelidir. Başka hiçbir yere sığmayan kolaylık metodları sağlar — tarih biçimlendirme, slug üretimi, response oluşturma.

#include "tools/Helper.h"

std::string slug = Helper::slug("Hello, World!"); // "hello-world"

JsonValue

İç içe nesneler ve diziler için yardımcılarla birlikte crow::json::wvalue üzerinde bir wrapper. Service ve controller metodlarının dönüş tipi olarak kullanın:

#include "tools/JsonValue.h"
using json = JsonValue;

json out;
out["status"] = "ok";
out["data"]   = json::Array();
out["data"].append({ {"id", 1}, {"name", "Ada"} });
return out;

Logger

Günlükleme sayfasında zaten kapsandı. Crow logger'ının erişilebilir olmadığı bir yerden bir şey loglamak istediğinizde kullanın.
