Kontrolcüler

Bir controller HTTP route'ları veri katmanına bağlar. Her biri Garvan::BaseContoller'ı genişletir ve beklediğiniz beş REST eylemini sergiler.

BaseController

Temel sınıf küçük bir sözleşme bildirir:

class BaseContoller : public Helper
{
public:
    virtual json index() = 0;          // GET /resource
    json         create(json model);   // POST /resource
    json         read(string id);      // GET /resource/:id
    json         update(json model);   // PUT /resource/:id
    void         erease();             // DELETE /resource/:id
    json         getById(string id);
};

Sadece index() pure-virtual — geri kalan her şeyin kaynak başına override edebileceğiniz bir default implementasyonu vardır.

REST eylemleri

Tipik bir resource controller:

// app/controllers/api/PostController.h
#pragma once
#include "controller/BaseContoller.h"
#include "../../services/PostService.h"

class PostController : public Garvan::BaseContoller
{
public:
    json index() override {
        PostService svc;
        return svc.index();
    }
};

routes/ApiRoutes.cpp'de bir route'a bağlayın:

CROW_ROUTE(app, "/api/posts")([] {
    PostController c;
    return jsonresponse{ c.index() };
});
