Modeller

Bir model bir veritabanı tablosunu temsil eder. Metadata (tablo adı, primary key, sütunlar) taşır ve ORM::OModel'den query-builder metodlarını miras alır.

BaseModel

Modellerinizi app/models/ altına yerleştirin. Minimal bir model:

// app/models/Post.h
#pragma once
#include "orm/omodel.h"

class Post : public ORM::OModel
{
public:
    Post() {
        table          = "posts";
        primaryKey     = "id";
        public_columns  = {"id", "title", "body", "user_id", "created_at"};
        private_columns = {};
    }
};

İlişkiler

Builder, OModel'in miras aldığı dört ilişki yardımcısı sergiler:

  • hasOne(model, foreignKey, localKey)
  • hasMany(model, foreignKey, ownerKey)
  • belongsTo(model, foreignKey, ownerKey)
  • belongsToMany(model, pivotTable, foreignKey, ownerKey)

Her biri get() çağırdığınızda çözülen bir join zamanlar. Laravel'den bilebileceğiniz ilişki API'sini yansıtırlar.

User u;
auto posts = u.find(42).hasMany(Post{}, "user_id", "id").get();
