JSON

Garvan JSON'u crow::json::rvalue aracılığıyla okur ve crow::json::wvalue aracılığıyla yazar. Request handler'ları dışında kullanım için tools dizininde ince bir wrapper olan JsonValue da vardır.

JSON okuma

Gelen bir request body'sini parse edin ve anahtara göre alanlara erişin:

CROW_ROUTE(app, "/api/echo")
    .methods("POST"_method)
([](const crow::request &req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "invalid json");

    std::string name = body["name"].s();
    int         age  = body["age"].i();
    return crow::response("hello " + name);
});

load parse başarısız olduğunda falsy bir değer döndürür, bu yüzden alanlara erişmeden önce her zaman kontrol edin.

JSON yazma

Bir wvalue oluşturun ve döndürün; Garvan Content-Type: application/json'u otomatik olarak ayarlar.

CROW_ROUTE(app, "/api/user")([] {
    crow::json::wvalue out;
    out["id"]      = 42;
    out["name"]    = "Ada";
    out["roles"]   = crow::json::wvalue::list({ "admin", "editor" });
    return out;
});

Garvan JsonValue

JsonValue (route header'ları içinde alias json), servisler içinde kullanım için birkaç kolaylık ekleyen ince bir wrapper'dır. Örneğin paketli starter'daki UserMysqlController, index() metodundan bir JsonValue döndürür.

#include "tools/JsonValue.h"
using json = JsonValue;

json users;
users.append({ {"id", 1}, {"name", "Ada"} });
users.append({ {"id", 2}, {"name", "Bo"} });
return users;
