Şablonlar (Mustache)

Garvan Crow'un mustache implementasyonunu sergiler. Model kasıtlı olarak basittir: bir şablon dosyası artı bir context nesnesi render edilmiş HTML'e eşittir.

Bileşenler

Her render iki parça içerir:

  • Page — diskteki bir dosya, bir crow::mustache::template_t'e yüklenir.
  • Context — şablonun etiketleri tarafından referans verilen değerleri taşıyan bir crow::mustache::context (crow::json::wvalue için alias).

Page

Şablonlar bir base dizin altında yaşar. Başlangıçta bir kez ayarlayın:

crow::mustache::set_global_base("public/");

Sonra o base'e göre dosyaları yükleyin:

auto page = crow::mustache::load("welcome.html");
auto text = crow::mustache::load_text("static_snippet.html"); // parse yok

Loader path'i sanitize eder; bunu kesinlikle atlamanız gerekirse (genellikle gerekmez), load_unsafe kullanın.

Context

Sayfanın ihtiyaç duyduğu verilerle bir context oluşturun:

crow::mustache::context ctx;
ctx["title"]   = "Welcome";
ctx["user"]    = "Ada";
ctx["items"]   = crow::json::wvalue::list({ "one", "two", "three" });
ctx["greet"]   = [](std::string) { return std::string("Hello there!"); };

Lambda'lara izin verilir ve kendileri mustache etiketleri içeren string'ler döndürebilir — engine parse etmeye devam eder.

Partial'lar

{{> partial.html }} sözdizimi ile parçaları yeniden kullanın. Path yine global base'e görelidir. Okuduğunuz docs sitesi top nav, sidebar, TOC ve footer için partial'lar kullanır.

<body>
    {{> topnav.html }}
    <main>{{& content}}</main>
    {{> footer.html }}
</body>

Bir şablon döndürme

Sayfayı context ile render edin ve sonucu döndürün:

CROW_ROUTE(app, "/welcome/<string>")([](std::string name) {
    auto page = crow::mustache::load("welcome.html");
    crow::mustache::context ctx;
    ctx["user"] = name;
    return page.render(ctx);
});

page.render(ctx) Content-Type'ı text/html'e ayarlanmış bir crow::returnable döndürür. Düz bir std::string'e sahip olmayı tercih ederseniz render_string(ctx) kullanın — örneğin sonucu başka bir şablon içine gömmek istediğinizde.

İpucu

Şablonunuzun edebi {{ içermesi gerekiyorsa (örneğin bu sayfa için bir kod örneği), onları HTML entity'leri &#123;&#123; ile escape edin.
