WebSockets

WebSockets, HTTP route'larınızla aynı port üzerinde iki yönlü, düşük gecikmeli kanallar sağlar. Garvan Crow'un WebSocket API'sini değişmeden sergiler.

Bir websocket route tanımlama

CROW_WEBSOCKET_ROUTE(app, "/ws")
    .onopen([&](crow::websocket::connection &conn) {
        CROW_LOG_INFO << "client connected: " << &conn;
    })
    .onmessage([&](crow::websocket::connection &conn,
                    const std::string &data, bool is_binary) {
        conn.send_text("you said: " + data);
    })
    .onclose([&](crow::websocket::connection &conn, const std::string &reason, uint16_t code) {
        CROW_LOG_INFO << "client gone: " << reason;
    });

Bağlantı olayları

Genellikle üç handler istersiniz: yeni bağlantıları takip etmek için onopen, gelen frame'ler için onmessage ve durumu temizlemek için onclose. Yayın yapmanız gerekiyorsa bağlantıları thread-safe bir konteynerde saklayın.
