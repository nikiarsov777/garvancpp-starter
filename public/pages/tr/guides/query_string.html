Sorgu dizeleri

Bir URL'deki ?'den sonraki her şey otomatik olarak parse edilir. req.url_params aracılığıyla erişin.

Temel kullanım

CROW_ROUTE(app, "/search")([](const crow::request &req) {
    const char *q = req.url_params.get("q");
    if (!q) return crow::response(400, "missing q");
    return crow::response("you searched for: " + std::string(q));
});

get() anahtar yoksa bir const char* veya nullptr döndürür — dereference etmeden önce her zaman kontrol edin.

Birden fazla değer

Listeler ?tag=a&tag=b olarak yazılır:

auto tags = req.url_params.get_list("tag");
for (const auto &t : tags) CROW_LOG_INFO << "tag: " << t;

application/x-www-form-urlencoded body'ler için (HTML formları için tipik), req.get_body_params()'i çağırın — API aynıdır.
