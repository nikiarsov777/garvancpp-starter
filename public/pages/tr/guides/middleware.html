Middleware

Bir middleware, app'ten akan her request ve response'u gözlemlemenize veya değiştirmenize izin verir — auth, günlükleme, CORS ve oturumlar tipik kullanım örnekleridir.

Middleware nedir

Her middleware üç şeye sahip bir struct'tır: request başına bir context, route çalışmadan önce çağrılan bir before_handle() hook'u ve sonra çağrılan bir after_handle() hook'u.

Bir middleware yazma

struct Timer
{
    struct context {
        std::chrono::steady_clock::time_point start;
    };

    void before_handle(crow::request &, crow::response &, context &ctx) {
        ctx.start = std::chrono::steady_clock::now();
    }

    void after_handle(crow::request &, crow::response &res, context &ctx) {
        auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::steady_clock::now() - ctx.start).count();
        res.set_header("X-Render-Time", std::to_string(ms) + "ms");
    }
};

Middleware kullanma

Middleware'leri crow::App'a template argümanları olarak ekleyin:

crow::App<Timer> app;

Bir handler içinde, context'inizi app.get_context<Timer>(req) ile alın.
