Test yazma

Handler'ları gerçek bir porta bind etmeden doğrudan çalıştırabilirsiniz. Crow, sentetik bir request üzerinde handle() çağırmanıza ve response'u incelemenize izin verir.

Unit testleri

#include "crow.h"
#include "doctest.h"

TEST_CASE("hello returns greeting") {
    crow::SimpleApp app;
    CROW_ROUTE(app, "/")([] { return "hi"; });

    crow::request req;
    req.url = "/";
    crow::response res;
    app.handle(req, res);

    CHECK(res.code == 200);
    CHECK(res.body == "hi");
}

Entegrasyon testleri

End-to-end kapsam için app'i run_async() ile başlatın ve libcurl veya herhangi bir HTTP istemcisi ile ona vurun:

auto handle = app.port(0).run_async();   // port 0 = auto-pick
auto port   = app.port();                  // bağlı port'u keşfet
// ... issue requests against http://localhost:port ...
app.stop();
