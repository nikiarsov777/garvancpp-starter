Rotalar

Bir route, HTTP metodu + URL desenini bir handler'a bağlar. Garvan Crow'un compile-time router'ını miras alır, bu router route tanımlarınızdan bir karar ağacı oluşturur — aramalar O(log n)'dir ve regex yoktur.

CROW_ROUTE macro'su

Bir route bildirmenin kanonik yolu:

CROW_ROUTE(app, "/hello")([] {
    return "hi";
});

Runtime'da path oluşturmanız gerekirse app.route_dynamic("/hello")'i de kullanabilirsiniz, ancak macro biçimi compile-time'da kontrol edildiği için tercih edilir.

URL parametreleri

Parametreleri açı parantezleri içine koyun ve onları handler'ınızın argümanları olarak kabul edin. Desteklenen tipler: int, uint, double, string ve path:

CROW_ROUTE(app, "/users/<int>")([](int id) {
    return std::to_string(id);
});

CROW_ROUTE(app, "/files/<path>")([](std::string rest) {
    return "you requested: " + rest;
});

HTTP metodları

Rotalar varsayılan olarak GET'tir. Ek verb'ler kaydetmek için .methods(...) kullanın:

CROW_ROUTE(app, "/users")
    .methods("GET"_method, "POST"_method)
([](const crow::request &req) {
    if (req.method == crow::HTTPMethod::POST) {
        return crow::response(201, "created");
    }
    return crow::response("user list");
});

Handler

Bir handler sıfır veya daha fazla argüman alabilir. İlk argüman header'lara ve body'e erişmek için const crow::request& olabilir; ikincisi cevabı artırımlı yazmak ve res.end()'ı kendiniz çağırmak istiyorsanız crow::response& olabilir.

Response

Body için bir std::string, veya status code veya header'ları açıkça ayarlamanız gerektiğinde bir crow::response döndürün:

return crow::response(404, "not found");

Catchall route'ları

Başka hiçbir route eşleşmediğinde çalışan bir fallback tanımlamak için CROW_CATCHALL_ROUTE(app) kullanın. Şu an okuduğunuz docs sitesi bilinmeyen path'leri bir page index'e karşı çözmek için bir tane kullanıyor.

CROW_CATCHALL_ROUTE(app)([](const crow::request &req) {
    return crow::response(404, "no such page: " + req.url);
});
