Multipart

Tarayıcılar bir form dosya input'ları içerdiğinde multipart/form-data gönderir. Garvan bu istekleri crow::multipart::message aracılığıyla parse eder.

Multipart okuma

CROW_ROUTE(app, "/upload")
    .methods("POST"_method)
([](const crow::request &req) {
    crow::multipart::message msg(req);
    for (const auto &part : msg.parts) {
        const std::string &name = part.headers.at("Content-Disposition").params.at("name");
        CROW_LOG_INFO << name << " = " << part.body.substr(0, 64);
    }
    return crow::response(200, "received");
});

Dosya yüklemeleri

Her part'ın body'si ham byte içerir; diske yazın:

if (part.headers.at("Content-Disposition").params.count("filename")) {
    std::ofstream out("/tmp/" + part.headers.at("Content-Disposition").params.at("filename"),
                      std::ios::binary);
    out << part.body;
}
Uyarı

İstemci tarafından sağlanan filename'e asla güvenmeyin. Path ayırıcılarını çıkarın ve diske yazmadan önce bir allow-list'e karşı doğrulayın.
