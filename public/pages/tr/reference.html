API Referansı

Bu sayfa Garvan ve Crow için üretilen API referansına bağlantı verir. Framework C++23 (GCC 14+ / Clang 18+) hedefler. Referans, kaynak ağacındaki header yorumlarından Doxygen tarafından üretilir.

Hakkında

Referans iki katmanı kapsar:

  • Garvan — model/controller/service temel sınıfları, ORM builder, migration runner ve vendors/Garvan/include/ altındaki yardımcılar.
  • Crow — altta yatan HTTP sunucusu, router, JSON, mustache, multipart ve websocket alt sistemleri.

Namespace'ler

  • Garvan — framework sınıfları (BaseContoller, BaseService, Builder, Migration, MigrationRunner).
  • ORM — OModel temeli ve ilgili tipler.
  • crow — upstream Crow'dan her şey: SimpleApp, App<...>, request, response, json::rvalue, json::wvalue, mustache::template_t.
Durum

Doxygen çıktısı henüz bu siteye bağlanmadı. O zamana kadar doğrudan vendors/Garvan/include/ ve vendors/Garvan/crow/'daki header'lara başvurun.
