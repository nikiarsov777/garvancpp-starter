8 satırda çalışır hale gelin

Bir route tanımlayın, bir string döndürün, uygulamayı çalıştırın. Garvan yolunuzdan çekilir.

#include "crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([]{
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}
CROW_ROUTE(app, "/api/users/<int>")
([](int id) {
    crow::json::wvalue user;
    user["id"]    = id;
    user["name"]  = "Ada";
    user["email"] = "ada@example.com";
    return user;
});

JSON, kolay yol

Bir handler'dan crow::json::wvalue döndürün, Garvan sizin için doğru Content-Type'ı ayarlar. Garvan'ın kendi JsonValue'su aynı primitive'leri servisler ve modeller içinde kullanım için sarar.

Tanıdık hissettiren bir ORM

Akıcı bir query builder desteklenen backend'lerin herhangi biri için SQL yazar. Modeller OModel'i genişletir ve find(), where() ve ilişkileri sergiler.

auto users = db.table("users")
    .where("active", "=", 1)
    .order_by("created_at", "desc")
    .limit(20)
    .get();
