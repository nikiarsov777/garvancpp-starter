İlk uygulamanız

Mümkün olan en küçük Garvan programı sadece birkaç satır C++'tır. Her parçanın ne yaptığından geçelim.

1. Include

Boş bir main.cpp ile başlayın ve Garvan ile paketlenmiş Crow header'ını dahil edin:

#include "vendors/Garvan/crow.h"

Bu tek header crow::SimpleApp, routing macro'ları, JSON değer tiplerini ve mustache template engine'i açar.

2. App bildirimi

main() içinde bir Crow uygulaması bildirin:

int main()
{
    crow::SimpleApp app;
}

SimpleApp HTTP sunucusunu, router'ı ve logger'ı tutar. Uygulama seviyesinde bağlı middleware'lere ihtiyacınız olduğunda crow::App<M1, M2, ...> kullanın — middleware kılavuzuna bakın.

3. Route ekleme

Bir route, bir URL desenini bir handler'a bağlar. CROW_ROUTE macro'su en yaygın yoldur:

CROW_ROUTE(app, "/")([] {
    return "Hello from Garvan!";
});

Lambda, bir istemci GET / istediğinde çağrılır. Bir std::string döndürmek onu yanıt gövdesi olarak geri gönderir.

4. Uygulamayı çalıştırma

Bir port seçin ve sunucuyu başlatın:

app.port(9090).multithreaded().run();

multithreaded() Crow'a CPU core başına bir worker kullanmasını söyler. run() süreç sonlanana kadar bloke eder; sunucuyla birlikte başka iş yapmanız gerekiyorsa run_async() kullanın.

Tam örnek

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([] {
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}

Derleyin ve http://localhost:9090'ı ziyaret edin — tarayıcınızda selamı görmelisiniz.
