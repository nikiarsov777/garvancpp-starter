Linux'ta kurulum

Bu sayfa Garvan'ı kurmanız ve ilk executable'ınızı bir Linux makinesinde derlemeniz için size rehberlik eder.

Gereksinimler

  • C++23 desteği olan bir C++ derleyicisi (GCC 14+ veya Clang 18+).
  • CMake 3.20 veya sonrası.
  • Asio development header'ları (1.28 veya sonrası).
  • libpq, libmysqlcppconn, libmongoc, libsqlite3, libmonetdb-mapi
  • libcurl — AppJobs::SendTestMail için SMTP taşıması; kalpasan runtime verb'leri tarafından da kullanılır.
  • Opsiyonel: HTTPS için OpenSSL, sıkıştırma için zlib.
Not

vendors/Garvan/'daki paketli libgarvan.a Crow'u zaten dahili olarak linkler, bu yüzden sadece yukarıdaki sistem kitaplıklarına ihtiyacınız var.

libgarvan'ı yükleme

En hızlı yol starter repository'sini klonlamak, zaten libgarvan.a, Crow header'ları ve çalışan bir CMakeLists.txt içerir:

git clone https://github.com/nikiarsov777/garvan-starter.git my-app
cd my-app

Debian/Ubuntu'da veritabanı sürücülerini tek komutla kurabilirsiniz:

sudo apt update
sudo apt install -y \
    build-essential cmake \
    libasio-dev libssl-dev zlib1g-dev \
    libcurl4-openssl-dev \
    libpqxx-dev libmysqlcppconn-dev libsqlite3-dev \
    libmongoc-dev libbson-dev
libcurl auto-linked

Starter'ın CMakeLists.txt'i libcurl'ı find_package(CURL REQUIRED) ile alır ve CURL::libcurl'ı app_bin'e linkler. Paket kurulduktan sonra manuel yapılandırma gerekmez.

Kaynaktan derleme

Garvan'ı kendiniz derlemek isterseniz (paketli archive yerine), kaynak ağacını klonlayın ve CMake çalıştırın:

git clone https://github.com/nikiarsov777/garvancpp-starter.git
cd garvan
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build

Projenizi derleme

Projenizin CMakeLists.txt'ine şunu ekleyin:

cmake_minimum_required(VERSION 3.20)
project(MyApp CXX)
set(CMAKE_CXX_STANDARD 23)

add_executable(my_app main.cpp)

target_include_directories(my_app PRIVATE
    vendors/Garvan
    vendors/Garvan/include
)

target_link_libraries(my_app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/vendors/Garvan/libgarvan.a
    pthread
)

Sonra derleyin:

cmake -S . -B build
cmake --build build
./build/my_app
