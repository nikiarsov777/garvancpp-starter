Basit bir web sayfası

Düz bir string döndürmek testler için iyidir, ancak çoğu uygulamanın gerçek HTML'e ihtiyacı vardır. Garvan template için Crow'un mustache engine'ini kullanır — diskten bir sayfa render edelim.

Statik sayfa

public/fancypage.html oluşturun:

<!DOCTYPE html>
<html>
<body>
    <p>Hello World!</p>
</body>
</html>

Şimdi mustache'a template'lerin nerede aranacağını söyleyin ve dosyayı bir handler'dan yükleyin:

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;
    crow::mustache::set_global_base("public/");

    CROW_ROUTE(app, "/")([] {
        return crow::mustache::load_text("fancypage.html");
    });

    app.port(9090).multithreaded().run();
}

load_text dosyayı mustache tag'lerini parse etmeden okur, bu yüzden tamamen statik HTML için en hızlı seçenektir.

Değişkenli sayfa

Veri enjekte etmek için load_text'ten load'a geçin, bir context oluşturun ve render edin. Template'i güncelleyin:

<!DOCTYPE html>
<html>
<body>
    <p>Hello {{name}}!</p>
</body>
</html>

Ve route:

CROW_ROUTE(app, "/<string>")([](std::string name) {
    auto page = crow::mustache::load("fancypage.html");
    crow::mustache::context ctx;
    ctx["name"] = name;
    return page.render(ctx);
});

/Ada'yı ziyaret etmek şimdi Hello Ada!'yı gösterecek. Context string'ler, sayılar, listeler ve hatta lambda'lar tutabilir — Crow'un implement ettiği tam mustache özellik kümesi için templating kılavuzuna bakın.
