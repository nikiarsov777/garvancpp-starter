macOS'ta kurulum

macOS'ta Garvan uygulamalarını build etmek Linux ile aynı şekilde çalışır — paketli libgarvan.a evrenseldir, sadece birkaç sistem kitaplığı yüklemeniz gerekir.

Gereksinimler

  • Xcode command line tools (xcode-select --install).
  • C++23 desteği olan bir C++ derleyicisi (Xcode 16+ Apple Clang veya Homebrew'dan LLVM Clang 18+).
  • CMake 3.20 veya sonrası.
  • Asio header'ları.
  • libcurl (macOS ile birlikte gelir; Homebrew'un curl'u daha yeni bir seçenektir).

Homebrew ile

En kolay yol Homebrew. İhtiyaç duyduğunuz build araçlarını ve DB sürücülerini yükleyin:

brew install cmake asio openssl@3 curl
brew install libpq mysql-connector-c++ mongo-cxx-driver sqlite
# C++23 için: Apple Clang eski ise yeni bir toolchain kurun
brew install llvm@18

Projenizi derleme

OpenSSL için Homebrew prefix'lerini CMake'e verin:

cmake -S . -B build \
    -DOPENSSL_ROOT_DIR=$(brew --prefix openssl@3) \
    -DCMAKE_PREFIX_PATH=$(brew --prefix)
cmake --build build
İpucu

Apple Silicon Mac'lerde tüm bağımlılıkların arm64 build olduğundan emin olun — x86_64 Homebrew ile arm64'ü karıştırmak link zamanında hata verir.
