Windows'ta kurulum

Garvan Windows'ta MSVC 2019/2022 veya MinGW-w64 ile derlenir. En basit workflow bağımlılıklar için vcpkg kullanır.

Gereksinimler

  • Visual Studio 2022 (17.5+) «Desktop development with C++» workload'u ile — C++23 desteği için gerekli.
  • CMake 3.20 (Visual Studio ile birlikte gelir).
  • vcpkg veya Asio, OpenSSL, libcurl ve DB istemcileri için önceden derlenmiş binary'ler.

vcpkg ile

git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install asio openssl zlib curl libpqxx sqlite3

MSVC ile derleme

Projeyi vcpkg toolchain ile yapılandırın:

cmake -S . -B build ^
    -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
Uyarı

Garvan şu anda MSVC için önceden derlenmiş bir libgarvan.lib göndermiyor. Windows'ta C++ ABI'nin toolchain'inizle eşleşmesi için Garvan'ı kaynaktan derlemelisiniz.
