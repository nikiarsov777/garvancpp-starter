Инсталация в macOS

Компилирането на Garvan приложения под macOS работи по същия начин като под Linux — готовият libgarvan.a е универсален; нужно е само да инсталирате няколко системни библиотеки.

Изисквания

  • Xcode command line tools (xcode-select --install).
  • C++ компилатор с поддръжка на C++23 (Xcode 16+ Apple Clang или LLVM Clang 18+ от Homebrew).
  • CMake 3.20 или по-нов.
  • Asio header-и.
  • libcurl (идва с macOS; curl от Homebrew е по-нова опция).

С Homebrew

Най-лесният път е през Homebrew. Инсталирайте инструментите за компилация и драйверите за нужните бази:

brew install cmake asio openssl@3 curl
brew install libpq mysql-connector-c++ mongo-cxx-driver sqlite
# За C++23: инсталирайте по-нов toolchain ако Apple Clang е стар
brew install llvm@18

Компилиране на проекта ви

Подайте на CMake пътищата до OpenSSL от Homebrew:

cmake -S . -B build \
    -DOPENSSL_ROOT_DIR=$(brew --prefix openssl@3) \
    -DCMAKE_PREFIX_PATH=$(brew --prefix)
cmake --build build
Съвет

На Apple Silicon Mac-ове внимавайте всички зависимости да са arm64 — смесването на x86_64 Homebrew с arm64 ще се счупи при линковане.
