Инсталация в Windows

Garvan се компилира под Windows с MSVC 2019/2022 или с MinGW-w64. Най-лесният работен поток използва vcpkg за зависимостите.

Изисквания

  • Visual Studio 2019 или по-нов, с пакета „Desktop development with C++".
  • CMake 3.20 (включен във Visual Studio).
  • vcpkg или предварително компилирани binary-та за Asio, OpenSSL и клиентите на базите данни.

С vcpkg

git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install asio openssl zlib libpqxx sqlite3

Компилация с MSVC

Конфигурирайте проекта с vcpkg toolchain:

cmake -S . -B build ^
    -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
Внимание

Garvan все още не доставя предкомпилиран libgarvan.lib за MSVC. На Windows компилирайте Garvan от изходен код, за да съответства C++ ABI с вашия toolchain.
