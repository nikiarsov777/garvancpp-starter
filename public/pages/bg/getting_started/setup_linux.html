Инсталация в Linux

Тази страница ще ви преведе през инсталирането на Garvan и компилирането на първия ви изпълним файл на Linux машина.

Изисквания

  • C++ компилатор с поддръжка на C++20 (GCC 11+ или Clang 12+).
  • CMake 3.20 или по-нов.
  • Asio header-и за разработка (1.28 или по-нови).
  • libpq, libmysqlcppconn, libmongoc, libsqlite3, libmonetdb-mapi
  • По избор: OpenSSL за HTTPS, zlib за компресия.
Бележка

Включеният libgarvan.a във vendors/Garvan/ вече линкова Crow вътрешно, така че имате нужда само от системните библиотеки по-горе.

Инсталиране на libgarvan

Най-бързият път е да клонирате стартовото хранилище, което вече съдържа libgarvan.a, header-ите на Crow и работещ CMakeLists.txt:

git clone https://github.com/nikiarsov777/garvan-starter.git my-app
cd my-app

На Debian/Ubuntu можете да инсталирате драйверите за бази с една команда:

sudo apt update
sudo apt install -y \
    build-essential cmake \
    libasio-dev libssl-dev zlib1g-dev \
    libpqxx-dev libmysqlcppconn-dev libsqlite3-dev \
    libmongoc-dev libbson-dev

Компилиране от изходен код

Ако искате да компилирате самия Garvan (вместо да ползвате готовия архив), клонирайте дървото на изходния код и пуснете CMake:

git clone https://github.com/nikiarsov777/garvancpp-starter.git
cd garvan
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build

Компилиране на проекта ви

Добавете следните редове в CMakeLists.txt на проекта ви:

cmake_minimum_required(VERSION 3.20)
project(MyApp CXX)
set(CMAKE_CXX_STANDARD 20)

add_executable(my_app main.cpp)

target_include_directories(my_app PRIVATE
    vendors/Garvan
    vendors/Garvan/include
)

target_link_libraries(my_app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/vendors/Garvan/libgarvan.a
    pthread
)

След това компилирайте:

cmake -S . -B build
cmake --build build
./build/my_app
