Вашето първо приложение

Най-малката възможна Garvan програма се състои от няколко реда C++. Нека минем през всяка част.

1. Включване

Започнете с празен main.cpp и включете header-а на Crow, доставен с Garvan:

#include "vendors/Garvan/crow.h"

Този единствен header предоставя crow::SimpleApp, макросите за маршрутизация, JSON типовете и mustache шаблонния двигател.

2. Декларация на приложението

Декларирайте Crow приложение в main():

int main()
{
    crow::SimpleApp app;
}

SimpleApp съдържа HTTP сървъра, рутера и логера. Използвайте crow::App<M1, M2, ...>, ако имате нужда от middleware-и, прикрепени на ниво приложение — вижте ръководството за middleware.

3. Добавяне на маршрути

Маршрутът свързва URL шаблон с обработчик. Макросът CROW_ROUTE е най-често използваният начин:

CROW_ROUTE(app, "/")([] {
    return "Здравей от Garvan!";
});

Lambda-та се извиква, когато клиент поиска GET /. Връщането на std::string го изпраща обратно като тяло на отговора.

4. Стартиране на приложението

Изберете порт и стартирайте сървъра:

app.port(9090).multithreaded().run();

multithreaded() казва на Crow да използва един worker на CPU ядро. run() блокира, докато процесът не приключи; използвайте run_async(), ако трябва да правите друга работа едновременно със сървъра.

Пълен пример

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([] {
        return "Здравей от Garvan!";
    });

    app.port(9090).multithreaded().run();
}

Компилирайте и посетете http://localhost:9090 — трябва да видите поздрава в браузъра си.
