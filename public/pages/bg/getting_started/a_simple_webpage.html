Проста уеб страница

Връщането на обикновен низ върши работа за тестове, но повечето приложения имат нужда от истински HTML. Garvan използва mustache двигателя на Crow за шаблоните — нека рендираме страница от диска.

Статична страница

Създайте public/fancypage.html:

<!DOCTYPE html>
<html>
<body>
    <p>Здравей, свят!</p>
</body>
</html>

Сега кажете на mustache къде да търси шаблони и заредете файла от handler:

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;
    crow::mustache::set_global_base("public/");

    CROW_ROUTE(app, "/")([] {
        return crow::mustache::load_text("fancypage.html");
    });

    app.port(9090).multithreaded().run();
}

load_text прочита файла без да парсва mustache тагове, така че е най-бързата опция за изцяло статичен HTML.

Страница с променлива

За да инжектирате данни, превключете от load_text към load, построете контекст и рендирайте. Обновете шаблона:

<!DOCTYPE html>
<html>
<body>
    <p>Здравей, {{name}}!</p>
</body>
</html>

И маршрутът:

CROW_ROUTE(app, "/<string>")([](std::string name) {
    auto page = crow::mustache::load("fancypage.html");
    crow::mustache::context ctx;
    ctx["name"] = name;
    return page.render(ctx);
});

Посещение на /Ада сега ще покаже Здравей, Ада!. Контекстът може да съдържа низове, числа, списъци и дори lambda-и — вижте ръководството за шаблони за всичко, което mustache на Crow поддържа.
