Garvan C++

Бърз, batteries-included C++23 уеб фреймуърк. Garvan надгражда Crow с ORM, миграции, event bus и job queue с реален SMTP mail job, слой модел/контролер/услуга и CLI kalpasan — за да доставяте HTTP, WebSocket и background работа без да напускате C++.

На крак за 8 реда

Дефинирайте маршрут, върнете низ, стартирайте приложението. Garvan не ви пречи.

#include "crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([]{
        return "Здравей от Garvan!";
    });

    app.port(9090).multithreaded().run();
}
CROW_ROUTE(app, "/api/users/<int>")
([](int id) {
    crow::json::wvalue user;
    user["id"]    = id;
    user["name"]  = "Ада";
    user["email"] = "ada@example.com";
    return user;
});

JSON, лесно

Върнете crow::json::wvalue от обработчик и Garvan ще зададе правилния Content-Type вместо вас. Собственият JsonValue на Garvan опакова същите примитиви за употреба в услуги и модели.

ORM, който усещате познат

Fluent query builder пише SQL за всеки от поддържаните backend-и. Моделите наследяват OModel и предоставят find(), where() и връзки.

auto users = db.table("users")
    .where("active", "=", 1)
    .order_by("created_at", "desc")
    .limit(20)
    .get();
