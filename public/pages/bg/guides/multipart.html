Multipart

Браузърите изпращат multipart/form-data, когато формата съдържа файлови полета. Garvan парсва тези заявки чрез crow::multipart::message.

Четене на multipart

CROW_ROUTE(app, "/upload")
    .methods("POST"_method)
([](const crow::request &req) {
    crow::multipart::message msg(req);
    for (const auto &part : msg.parts) {
        const std::string &name = part.headers.at("Content-Disposition").params.at("name");
        CROW_LOG_INFO << name << " = " << part.body.substr(0, 64);
    }
    return crow::response(200, "получено");
});

Качване на файлове

Тялото на всяка част съдържа сурови байтове; запишете го на диска:

if (part.headers.at("Content-Disposition").params.count("filename")) {
    std::ofstream out("/tmp/" + part.headers.at("Content-Disposition").params.at("filename"),
                      std::ios::binary);
    out << part.body;
}
Внимание

Никога не вярвайте на име на файл, подадено от клиент. Премахнете path-разделителите и валидирайте срещу разрешен списък преди да пишете на диска.
