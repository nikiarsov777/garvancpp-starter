Blueprints

Blueprint е група маршрути, които споделят URL префикс, базова директория за шаблони или статична директория. Удобни са, когато искате да разделите голямо приложение на модули — например един blueprint за всяка API версия.

Създаване на blueprint

crow::Blueprint api("api/v1", "static_v1", "templates_v1");

CROW_BP_ROUTE(api, "/users")([] {
    return "v1 потребители";
});

Прикрепяне към приложението

app.register_blueprint(api);

Префиксът на blueprint-а се добавя пред всеки маршрут в него, така че handler-ът горе отговаря на GET /api/v1/users.
