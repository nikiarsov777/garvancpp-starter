WebSockets

WebSockets ви предоставят двупосочни канали с ниска латентност на същия порт като вашите HTTP маршрути. Garvan експонира WebSocket API на Crow непроменено.

Дефиниране на websocket маршрут

CROW_WEBSOCKET_ROUTE(app, "/ws")
    .onopen([&](crow::websocket::connection &conn) {
        CROW_LOG_INFO << "клиент се свърза: " << &conn;
    })
    .onmessage([&](crow::websocket::connection &conn,
                    const std::string &data, bool is_binary) {
        conn.send_text("казахте: " + data);
    })
    .onclose([&](crow::websocket::connection &conn, const std::string &reason, uint16_t code) {
        CROW_LOG_INFO << "клиент излезе: " << reason;
    });

Събития на връзка

Обикновено ще искате три handler-а: onopen, за да следите нови връзки, onmessage за входящи frame-ове, и onclose, за да изчистите състоянието. Съхранявайте връзките в thread-safe контейнер, ако ще излъчвате.
