Шаблони (Mustache)

Garvan предоставя mustache имплементацията на Crow. Моделът е умишлено прост: шаблонен файл + контекстен обект = рендиран HTML.

Компоненти

Всяко рендиране включва две части:

  • Страница — файл на диска, зареден в crow::mustache::template_t.
  • Контекст — crow::mustache::context (алиас на crow::json::wvalue) със стойностите, на които таговете на шаблона се позовават.

Страница

Шаблоните живеят в базова директория. Задайте я веднъж при стартиране:

crow::mustache::set_global_base("public/");

След това зареждайте файлове относително спрямо тази база:

auto page = crow::mustache::load("welcome.html");
auto text = crow::mustache::load_text("static_snippet.html"); // без парсване

Зареждащият функция санитизира пътя; ако наистина имате нужда да заобиколите това (обикновено нямате), използвайте load_unsafe.

Контекст

Постройте контекст с каквито данни страницата има нужда:

crow::mustache::context ctx;
ctx["title"]   = "Добре дошли";
ctx["user"]    = "Ада";
ctx["items"]   = crow::json::wvalue::list({ "едно", "две", "три" });
ctx["greet"]   = [](std::string) { return std::string("Здравейте!"); };

Lambda-те са разрешени и могат сами да връщат низове, съдържащи mustache тагове — двигателят продължава да парсва.

Партиали

Преизползвайте фрагменти със синтаксиса {{> partial.html }}. Пътят отново е относителен спрямо глобалната база. Документационният сайт, който четете, използва партиали за горната навигация, sidebar-а, TOC-а и footer-а.

<body>
    {{> topnav.html }}
    <main>{{& content}}</main>
    {{> footer.html }}
</body>

Връщане на шаблон

Рендирайте страницата с контекста и върнете резултата:

CROW_ROUTE(app, "/welcome/<string>")([](std::string name) {
    auto page = crow::mustache::load("welcome.html");
    crow::mustache::context ctx;
    ctx["user"] = name;
    return page.render(ctx);
});

page.render(ctx) връща crow::returnable с Content-Type, зададен на text/html. Използвайте render_string(ctx), ако предпочитате обикновен std::string — например когато искате да вградите резултата в друг шаблон.

Съвет
