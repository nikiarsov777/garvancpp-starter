JSON

Garvan чете JSON чрез crow::json::rvalue и пише чрез crow::json::wvalue. Има и тънка обвивка JsonValue в директорията с tools за употреба извън handler-и.

Четене на JSON

Парсвайте тяло на входяща заявка и достъпвайте полета по ключ:

CROW_ROUTE(app, "/api/echo")
    .methods("POST"_method)
([](const crow::request &req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "невалиден json");

    std::string name = body["name"].s();
    int         age  = body["age"].i();
    return crow::response("здравей " + name);
});

load връща falsy стойност при неуспешно парсване, така че винаги проверявайте преди достъп до полета.

Писане на JSON

Постройте wvalue и го върнете; Garvan автоматично задава Content-Type: application/json.

CROW_ROUTE(app, "/api/user")([] {
    crow::json::wvalue out;
    out["id"]      = 42;
    out["name"]    = "Ада";
    out["roles"]   = crow::json::wvalue::list({ "admin", "editor" });
    return out;
});

JsonValue на Garvan

JsonValue (alias json в header-ите на маршрутите) е лека обвивка, която добавя няколко удобства за употреба в услуги. Например UserMysqlController в комплекта стартов проект връща JsonValue от своя index() метод.

#include "tools/JsonValue.h"
using json = JsonValue;

json users;
users.append({ {"id", 1}, {"name", "Ада"} });
users.append({ {"id", 2}, {"name", "Бо"} });
return users;
