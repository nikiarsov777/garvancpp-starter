Тестване

Можете да упражнявате handler-ите директно, без да се свързвате с истински порт. Crow ви позволява да извикате handle() върху синтетична заявка и да инспектирате отговора.

Юнит тестове

#include "crow.h"
#include "doctest.h"

TEST_CASE("hello връща поздрав") {
    crow::SimpleApp app;
    CROW_ROUTE(app, "/")([] { return "здравей"; });

    crow::request req;
    req.url = "/";
    crow::response res;
    app.handle(req, res);

    CHECK(res.code == 200);
    CHECK(res.body == "здравей");
}

Интеграционни тестове

За end-to-end покритие стартирайте приложението с run_async() и го атакувайте с libcurl или произволен HTTP клиент:

auto handle = app.port(0).run_async();   // port 0 = автоматичен избор
auto port   = app.port();                  // открийте свързания порт
// ... издавайте заявки към http://localhost:port ...
app.stop();
