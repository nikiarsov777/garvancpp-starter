Маршрути

Маршрутът свързва HTTP метод + URL шаблон с обработчик. Garvan наследява compile-time рутера на Crow, който изгражда решаващо дърво от вашите дефиниции на маршрути — търсенията са O(log n) и не се използват регулярни изрази.

Макросът CROW_ROUTE

Каноничният начин за деклариране на маршрут:

CROW_ROUTE(app, "/hello")([] {
    return "здравей";
});

Можете да използвате и app.route_dynamic("/hello"), ако трябва да конструирате пътища по време на изпълнение, но макрос-формата е препоръчителна, защото се проверява при компилация.

URL параметри

Поставете параметри в ъглови скоби и ги приемете като аргументи на handler-а. Поддържат се int, uint, double, string и path:

CROW_ROUTE(app, "/users/<int>")([](int id) {
    return std::to_string(id);
});

CROW_ROUTE(app, "/files/<path>")([](std::string rest) {
    return "поискахте: " + rest;
});

HTTP методи

Маршрутите по подразбиране са GET. Използвайте .methods(...), за да регистрирате допълнителни глаголи:

CROW_ROUTE(app, "/users")
    .methods("GET"_method, "POST"_method)
([](const crow::request &req) {
    if (req.method == crow::HTTPMethod::POST) {
        return crow::response(201, "created");
    }
    return crow::response("списък потребители");
});

Handler

Handler-ът може да приема нула или повече аргументи. Първият може да е const crow::request& за достъп до header-и и тяло; вторият може да е crow::response&, ако искате да пишете отговора инкрементално и да извикате res.end() сами.

Отговор

Върнете std::string за тяло, или crow::response, когато имате нужда да зададете статус код или header-и явно:

return crow::response(404, "не е намерено");

Catchall маршрути

Използвайте CROW_CATCHALL_ROUTE(app), за да дефинирате резервен маршрут, който се изпълнява, когато никой друг маршрут не съвпада. Документационният сайт, който четете, използва точно такъв, за да разрешава непознати пътища спрямо индекс на страниците.

CROW_CATCHALL_ROUTE(app)([](const crow::request &req) {
    return crow::response(404, "няма такава страница: " + req.url);
});
