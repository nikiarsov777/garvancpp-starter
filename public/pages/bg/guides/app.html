Приложение (App)

Garvan приложението е обектът, който свързва HTTP сървъра, рутера, логера и регистрираните middleware-и. Ще го срещате във всеки проект.

SimpleApp

Най-често срещаният избор е crow::SimpleApp. Той няма middleware-и, прикрепени на ниво приложение — само маршрути.

crow::SimpleApp app;
CROW_ROUTE(app, "/")([] { return "ok"; });
app.port(9090).run();

App с middleware

Когато имате нужди, които обхващат цялата заявка (оторизация, сесии, CORS и т.н.), използвайте crow::App<M1, M2, ...>. Middleware-ите се комбинират отляво надясно и се разгъват по време на компилация.

struct AuthMW { struct context {}; void before_handle(...) {} void after_handle(...) {} };

crow::App<AuthMW> app;

Верижно извикване

Конфигурационните методи могат да се извикват верижно, което прави точката на влизане четима:

app.bindaddr("0.0.0.0")
   .port(9090)
   .multithreaded()
   .run();

Стартиране асинхронно

run() блокира извикващата нишка. Ако имате нужда да продължите да правите друга работа, запазете handle-а, върнат от run_async() — нека променливата излезе от scope и сървърът ще се спре.

auto handle = app.port(9090).run_async();
// ... друга работа ...
app.stop();
