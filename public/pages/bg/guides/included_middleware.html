Вградени middleware-и

Crow доставя няколко готови middleware-а; Garvan ги експонира всичките. Включете онези, които ви трябват, и ги добавете като template параметър към crow::App.

CORS handler

#include "crow/middlewares/cors.h"

crow::App<crow::CORSHandler> app;
auto &cors = app.get_middleware<crow::CORSHandler>();
cors.global().origin("https://example.com").allow_credentials();

Cookie parser

#include "crow/middlewares/cookie_parser.h"

crow::App<crow::CookieParser> app;

CROW_ROUTE(app, "/whoami")([&](const crow::request &req) {
    auto &cookies = app.get_context<crow::CookieParser>(req);
    return cookies.get_cookie("session");
});

Session middleware

Session middleware-ът е изграден върху cookie parser-а и съхранява произволни key/value данни на сървъра.

#include "crow/middlewares/session.h"

crow::App<crow::CookieParser, crow::SessionMiddleware<crow::InMemoryStore>> app{
    crow::SessionMiddleware<crow::InMemoryStore>{}
};
