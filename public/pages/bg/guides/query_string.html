Параметри в URL

Всичко след ? в URL се парсва автоматично. Достъпвайте го през req.url_params.

Основна употреба

CROW_ROUTE(app, "/search")([](const crow::request &req) {
    const char *q = req.url_params.get("q");
    if (!q) return crow::response(400, "липсва q");
    return crow::response("търсихте: " + std::string(q));
});

get() връща const char* или nullptr, когато ключът липсва — винаги проверявайте преди дереференция.

Множество стойности

Списъците се записват като ?tag=a&tag=b:

auto tags = req.url_params.get_list("tag");
for (const auto &t : tags) CROW_LOG_INFO << "tag: " << t;

За тела от тип application/x-www-form-urlencoded (типични за HTML форми) извикайте req.get_body_params() — API-то е идентично.
