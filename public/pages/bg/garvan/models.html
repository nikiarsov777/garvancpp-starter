Модели

Моделът представя една таблица в базата. Носи метаданни (име на таблица, primary key, колони) и наследява query-builder методите от ORM::OModel.

BaseModel

Поставете моделите си в app/models/. Минимален модел:

// app/models/Post.h
#pragma once
#include "orm/omodel.h"

class Post : public ORM::OModel
{
public:
    Post() {
        table          = "posts";
        primaryKey     = "id";
        public_columns  = {"id", "title", "body", "user_id", "created_at"};
        private_columns = {};
    }
};

Връзки

Builder експонира четири relation helper-а, които OModel наследява:

  • hasOne(model, foreignKey, localKey)
  • hasMany(model, foreignKey, ownerKey)
  • belongsTo(model, foreignKey, ownerKey)
  • belongsToMany(model, pivotTable, foreignKey, ownerKey)

Всеки от тях планира join, който се изпълнява, когато извикате get(). Тези методи отразяват relation API-то, познато от Laravel.

User u;
auto posts = u.find(42).hasMany(Post{}, "user_id", "id").get();
