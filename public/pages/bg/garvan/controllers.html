Контролери

Контролерът свързва HTTP маршрутите със слоя за данни. Всеки наследява Garvan::BaseContoller и експонира петте REST действия, които очаквате.

BaseController

Базовият клас декларира малък контракт:

class BaseContoller : public Helper
{
public:
    virtual json index() = 0;          // GET /resource
    json         create(json model);   // POST /resource
    json         read(string id);      // GET /resource/:id
    json         update(json model);   // PUT /resource/:id
    void         erease();             // DELETE /resource/:id
    json         getById(string id);
};

Само index() е чисто виртуален — всичко останало има стандартна имплементация, която можете да override-нете за всеки ресурс.

REST действия

Типичен контролер за ресурс:

// app/controllers/api/PostController.h
#pragma once
#include "controller/BaseContoller.h"
#include "../../services/PostService.h"

class PostController : public Garvan::BaseContoller
{
public:
    json index() override {
        PostService svc;
        return svc.index();
    }
};

Свържете го с маршрут в routes/ApiRoutes.cpp:

CROW_ROUTE(app, "/api/posts")([] {
    PostController c;
    return jsonresponse{ c.index() };
});
