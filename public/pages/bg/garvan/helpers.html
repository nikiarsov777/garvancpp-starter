Помощни инструменти

Три малки помощни класа живеят под vendors/Garvan/include/tools/. Ще ги срещнете, докато пишете контролери и услуги.

Helper

Класът Helper е базата както на BaseContoller, така и на BaseService. Предоставя удобства, които не се вписват другаде — форматиране на дати, генериране на slug-ове, изграждане на отговор.

#include "tools/Helper.h"

std::string slug = Helper::slug("Здравей, свят!"); // "zdravey-svyat"

JsonValue

Обвивка около crow::json::wvalue с помощници за вложени обекти и масиви. Използвайте я като return тип на методите на услуги и контролери:

#include "tools/JsonValue.h"
using json = JsonValue;

json out;
out["status"] = "ok";
out["data"]   = json::Array();
out["data"].append({ {"id", 1}, {"name", "Ада"} });
return out;

Logger

Вече е обсъдено в страницата Логиране. Използвайте го всеки път, когато искате да логнете нещо от място, където логерът на Crow не е достижим.
