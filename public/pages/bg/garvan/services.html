Услуги

Услугите стоят между контролерите и моделите. Съдържат бизнес логиката, която не принадлежи нито в едните, нито в другите — валидация, операции с няколко таблици, обаждания към външни API.

BaseService

Базовият клас отразява BaseContoller, но всички методи са виртуални:

class BaseService : public Helper
{
public:
    virtual json index();
    virtual json create(json model);
    json         create(const crow::request &req); // удобство: парсва тялото вместо вас
    virtual json read(string id);
    virtual json update(json model);
    virtual void erease();
    virtual json getById(string id);
};

Употреба в контролер

Инстанцирайте услугата в метода на контролера, или я инжектирайте през конструктора:

json PostController::index()
{
    PostService svc;
    auto posts = svc.index();

    // post-processing: скриване на лични полета, добавяне на pagination и т.н.
    json out;
    out["data"]  = posts;
    out["count"] = posts.size();
    return out;
}

Слоят с услуги също улеснява тестването — контролерите стават тънки shim-ове, а услугите могат да се упражняват без да стартирате HTTP сървъра.
