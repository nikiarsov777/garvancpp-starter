Referência da API

Esta página liga à referência de API gerada para Garvan e Crow. O framework tem como alvo C++23 (GCC 14+ / Clang 18+). A referência é produzida pelo Doxygen a partir de comentários nos headers da árvore de código fonte.

Sobre

A referência cobre duas camadas:

  • Garvan — as classes base model/controller/service, o ORM builder, o migration runner e os utilitários em vendors/Garvan/include/.
  • Crow — o servidor HTTP subjacente, router, JSON, mustache, multipart e subsistemas websocket.

Namespaces

  • Garvan — classes do framework (BaseContoller, BaseService, Builder, Migration, MigrationRunner).
  • ORM — a base OModel e tipos relacionados.
  • crow — tudo do upstream Crow: SimpleApp, App<...>, request, response, json::rvalue, json::wvalue, mustache::template_t.
Estado

A saída do Doxygen ainda não está ligada a este site. Até lá, consulte diretamente os headers em vendors/Garvan/include/ e vendors/Garvan/crow/.
