Garvan C++

Um framework web C++ rápido e fácil de usar. O Garvan estende o Crow com um ORM, migrações, uma camada modelo/controlador/serviço e uma caixa de ferramentas de linha de comandos — para que possa entregar serviços HTTP e WebSocket sem sair do C++.
