Garvan C++

A correr em 8 linhas

Defina uma rota, devolva uma string, corra a app. Garvan sai do caminho.

#include "crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([]{
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}
CROW_ROUTE(app, "/api/users/<int>")
([](int id) {
    crow::json::wvalue user;
    user["id"]    = id;
    user["name"]  = "Ada";
    user["email"] = "ada@example.com";
    return user;
});

JSON, o caminho fácil

Devolva um crow::json::wvalue de um handler e o Garvan define o Content-Type certo por si. O próprio JsonValue do Garvan envolve as mesmas primitivas para uso dentro de services e modelos.

Um ORM que parece familiar

Um query builder fluente escreve o SQL para qualquer um dos backends suportados. Os modelos estendem OModel e expõem find(), where() e relações.

auto users = db.table("users")
    .where("active", "=", 1)
    .order_by("created_at", "desc")
    .limit(20)
    .get();
