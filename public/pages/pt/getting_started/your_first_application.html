A sua primeira aplicação

O programa Garvan mais pequeno possível são apenas algumas linhas de C++. Vamos ver o que cada parte faz.

1. Include

Comece com um main.cpp vazio e inclua o header Crow empacotado com Garvan:

#include "vendors/Garvan/crow.h"

Este único header expõe crow::SimpleApp, as macros de routing, os tipos de valor JSON e o motor de templates mustache.

2. Declaração da app

Declare uma aplicação Crow dentro de main():

int main()
{
    crow::SimpleApp app;
}

SimpleApp contém o servidor HTTP, o router e o logger. Use crow::App<M1, M2, ...> quando precisar de middlewares ligados ao nível da aplicação — ver o guia de middleware.

3. Adicionar routes

Um route liga um padrão URL a um handler. A macro CROW_ROUTE é a forma mais comum:

CROW_ROUTE(app, "/")([] {
    return "Hello from Garvan!";
});

A lambda é chamada sempre que um cliente pede GET /. Devolver uma std::string envia-a de volta como corpo da resposta.

4. Executar a app

Escolha uma porta e inicie o servidor:

app.port(9090).multithreaded().run();

multithreaded() diz ao Crow para usar um worker por core CPU. run() bloqueia até o processo terminar; use run_async() se precisar de fazer outro trabalho em paralelo com o servidor.

Exemplo completo

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([] {
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}

Compile e visite http://localhost:9090 — deverá ver a saudação no seu browser.
