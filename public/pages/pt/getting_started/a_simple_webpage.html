Uma página web simples

Devolver uma string simples é bom para testes, mas a maioria das aplicações precisa de HTML real. Garvan usa o motor mustache do Crow para templating — vamos renderizar uma página a partir do disco.

Página estática

Crie public/fancypage.html:

<!DOCTYPE html>
<html>
<body>
    <p>Hello World!</p>
</body>
</html>

Agora diga ao mustache onde procurar templates e carregue o ficheiro a partir de um handler:

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;
    crow::mustache::set_global_base("public/");

    CROW_ROUTE(app, "/")([] {
        return crow::mustache::load_text("fancypage.html");
    });

    app.port(9090).multithreaded().run();
}

load_text lê o ficheiro sem parse de tags mustache, portanto é a opção mais rápida para HTML puramente estático.

Página com uma variável

Para injetar dados, mude de load_text para load, construa um context e faça render. Atualize o template:

<!DOCTYPE html>
<html>
<body>
    <p>Hello {{name}}!</p>
</body>
</html>

E o route:

CROW_ROUTE(app, "/<string>")([](std::string name) {
    auto page = crow::mustache::load("fancypage.html");
    crow::mustache::context ctx;
    ctx["name"] = name;
    return page.render(ctx);
});

Visitar /Ada agora mostra Hello Ada!. O context pode conter strings, números, listas e até lambdas — ver o guia de templating para o conjunto completo de features mustache que o Crow implementa.
