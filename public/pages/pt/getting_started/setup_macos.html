Instalação em macOS

Construir apps Garvan em macOS funciona da mesma forma que em Linux — o libgarvan.a incluído é universal, só precisa de instalar algumas bibliotecas do sistema.

Requisitos

  • Xcode command line tools (xcode-select --install).
  • Um compilador C++ com suporte a C++23 (Apple Clang do Xcode 16+ ou LLVM Clang 18+ do Homebrew).
  • CMake 3.20 ou posterior.
  • Headers do Asio.
  • libcurl (incluído no macOS; o curl do Homebrew é uma opção mais recente).

Usando Homebrew

A via mais fácil é Homebrew. Instale as ferramentas de build e os drivers de BD que precisar:

brew install cmake asio openssl@3 curl
brew install libpq mysql-connector-c++ mongo-cxx-driver sqlite
# Para C++23: instale um toolchain mais recente se o Apple Clang for antigo
brew install llvm@18

Compilar o seu projeto

Aponte o CMake aos prefixos do Homebrew para OpenSSL:

cmake -S . -B build \
    -DOPENSSL_ROOT_DIR=$(brew --prefix openssl@3) \
    -DCMAKE_PREFIX_PATH=$(brew --prefix)
cmake --build build
Dica

Em Macs com Apple Silicon, certifique-se de que todas as dependências são builds arm64 — misturar Homebrew x86_64 com arm64 falha no link.
