Instalação em Linux

Esta página guia-o pela instalação do Garvan e pela compilação do seu primeiro executável numa máquina Linux.

Requisitos

  • Um compilador C++ com suporte a C++23 (GCC 14+ ou Clang 18+).
  • CMake 3.20 ou posterior.
  • Headers de desenvolvimento do Asio (1.28 ou posterior).
  • libpq, libmysqlcppconn, libmongoc, libsqlite3, libmonetdb-mapi
  • libcurl — transporte SMTP para AppJobs::SendTestMail; também usado pelos runtime verbs do kalpasan.
  • Opcional: OpenSSL para HTTPS, zlib para compressão.
Nota

O libgarvan.a incluído em vendors/Garvan/ já liga o Crow internamente, portanto só precisa das bibliotecas de sistema listadas acima.

Instalar libgarvan

A via mais rápida é clonar o repositório starter, que já traz libgarvan.a, os headers do Crow e um CMakeLists.txt a funcionar:

git clone https://github.com/nikiarsov777/garvan-starter.git my-app
cd my-app

Em Debian/Ubuntu pode instalar os drivers de BD numa só vez:

sudo apt update
sudo apt install -y \
    build-essential cmake \
    libasio-dev libssl-dev zlib1g-dev \
    libcurl4-openssl-dev \
    libpqxx-dev libmysqlcppconn-dev libsqlite3-dev \
    libmongoc-dev libbson-dev
libcurl auto-linked

O CMakeLists.txt do starter apanha o libcurl via find_package(CURL REQUIRED) e liga CURL::libcurl ao app_bin. Não é preciso configuração manual depois de o pacote estar instalado.

Compilar a partir do código fonte

Se quiser compilar o próprio Garvan (em vez de usar o archive incluído), clone a árvore de código e corra o CMake:

git clone https://github.com/nikiarsov777/garvancpp-starter.git
cd garvan
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build

Compilar o seu projeto

Adicione o seguinte ao CMakeLists.txt do seu projeto:

cmake_minimum_required(VERSION 3.20)
project(MyApp CXX)
set(CMAKE_CXX_STANDARD 23)

add_executable(my_app main.cpp)

target_include_directories(my_app PRIVATE
    vendors/Garvan
    vendors/Garvan/include
)

target_link_libraries(my_app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/vendors/Garvan/libgarvan.a
    pthread
)

Depois compile:

cmake -S . -B build
cmake --build build
./build/my_app
