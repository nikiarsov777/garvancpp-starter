Instalação em Windows

Garvan compila em Windows com MSVC 2019/2022 ou MinGW-w64. O workflow mais simples usa vcpkg para as dependências.

Requisitos

  • Visual Studio 2022 (17.5+) com o workload «Desktop development with C++» — necessário para C++23.
  • CMake 3.20 (incluído no Visual Studio).
  • vcpkg ou binários pré-construídos para Asio, OpenSSL, libcurl e clientes de BD.

Usando vcpkg

git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install asio openssl zlib curl libpqxx sqlite3

Compilar com MSVC

Configure o seu projeto com o toolchain do vcpkg:

cmake -S . -B build ^
    -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
Aviso

Garvan atualmente não fornece um libgarvan.lib pré-compilado para MSVC. Em Windows deve compilar o Garvan a partir do código fonte para que o ABI C++ coincida com o seu toolchain.
