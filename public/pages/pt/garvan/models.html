Modelos

Um modelo representa uma tabela da base de dados. Transporta metadados (nome da tabela, primary key, colunas) e herda os métodos do query builder de ORM::OModel.

BaseModel

Coloque os seus modelos em app/models/. Um modelo mínimo:

// app/models/Post.h
#pragma once
#include "orm/omodel.h"

class Post : public ORM::OModel
{
public:
    Post() {
        table          = "posts";
        primaryKey     = "id";
        public_columns  = {"id", "title", "body", "user_id", "created_at"};
        private_columns = {};
    }
};

Relações

Builder expõe quatro helpers de relação que OModel herda:

  • hasOne(model, foreignKey, localKey)
  • hasMany(model, foreignKey, ownerKey)
  • belongsTo(model, foreignKey, ownerKey)
  • belongsToMany(model, pivotTable, foreignKey, ownerKey)

Cada um agenda um join que é resolvido quando chama get(). Espelham a API de relações que talvez conheça do Laravel.

User u;
auto posts = u.find(42).hasMany(Post{}, "user_id", "id").get();
