Controladores

Um controller liga rotas HTTP à camada de dados. Cada um estende Garvan::BaseContoller e expõe as cinco ações REST que se esperam.

BaseController

A classe base declara um pequeno contrato:

class BaseContoller : public Helper
{
public:
    virtual json index() = 0;          // GET /resource
    json         create(json model);   // POST /resource
    json         read(string id);      // GET /resource/:id
    json         update(json model);   // PUT /resource/:id
    void         erease();             // DELETE /resource/:id
    json         getById(string id);
};

Apenas index() é puro virtual — tudo o resto tem uma implementação por defeito que pode sobrescrever por recurso.

Ações REST

Um controller de recurso típico:

// app/controllers/api/PostController.h
#pragma once
#include "controller/BaseContoller.h"
#include "../../services/PostService.h"

class PostController : public Garvan::BaseContoller
{
public:
    json index() override {
        PostService svc;
        return svc.index();
    }
};

Ligue-o a uma rota em routes/ApiRoutes.cpp:

CROW_ROUTE(app, "/api/posts")([] {
    PostController c;
    return jsonresponse{ c.index() };
});
