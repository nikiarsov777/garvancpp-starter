Utilitários

Três pequenas classes utilitárias vivem em vendors/Garvan/include/tools/. Vai encontrá-las enquanto escreve controllers e serviços.

Helper

A classe Helper é a base tanto do BaseContoller como do BaseService. Fornece métodos de conveniência que não encaixam noutro lado — formatação de datas, geração de slugs, construção de respostas.

#include "tools/Helper.h"

std::string slug = Helper::slug("Hello, World!"); // "hello-world"

JsonValue

Um wrapper sobre crow::json::wvalue com helpers para objetos e arrays aninhados. Use-o como tipo de retorno dos métodos de service e controller:

#include "tools/JsonValue.h"
using json = JsonValue;

json out;
out["status"] = "ok";
out["data"]   = json::Array();
out["data"].append({ {"id", 1}, {"name", "Ada"} });
return out;

Logger

Já coberto na página Registo. Use-o sempre que quiser fazer log de algo a partir de um sítio onde o logger do Crow não é alcançável.
