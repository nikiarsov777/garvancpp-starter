Escrever testes

Pode exercitar handlers diretamente sem fazer bind a uma porta real. O Crow permite-lhe chamar handle() num request sintético e inspecionar a resposta.

Testes unitários

#include "crow.h"
#include "doctest.h"

TEST_CASE("hello returns greeting") {
    crow::SimpleApp app;
    CROW_ROUTE(app, "/")([] { return "hi"; });

    crow::request req;
    req.url = "/";
    crow::response res;
    app.handle(req, res);

    CHECK(res.code == 200);
    CHECK(res.body == "hi");
}

Testes de integração

Para cobertura end-to-end, arranque a app com run_async() e bata nela com libcurl ou qualquer cliente HTTP:

auto handle = app.port(0).run_async();   // port 0 = auto-pick
auto port   = app.port();                  // descubra a porta bound
// ... issue requests against http://localhost:port ...
app.stop();
