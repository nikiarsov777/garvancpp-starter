Rotas

Uma rota liga um método HTTP + padrão URL a um handler. Garvan herda o router compile-time do Crow, que constrói uma árvore de decisão a partir das suas definições de rota — as pesquisas são O(log n) e não há regex envolvida.

A macro CROW_ROUTE

A forma canónica de declarar uma rota:

CROW_ROUTE(app, "/hello")([] {
    return "hi";
});

Também pode usar app.route_dynamic("/hello") se precisar de construir paths em runtime, mas a forma macro é preferida porque é verificada em compile time.

Parâmetros URL

Coloque parâmetros em parênteses angulares e aceite-os como argumentos do seu handler. Os tipos suportados são int, uint, double, string e path:

CROW_ROUTE(app, "/users/<int>")([](int id) {
    return std::to_string(id);
});

CROW_ROUTE(app, "/files/<path>")([](std::string rest) {
    return "you requested: " + rest;
});

Métodos HTTP

As rotas são por defeito GET. Use .methods(...) para registar verbos adicionais:

CROW_ROUTE(app, "/users")
    .methods("GET"_method, "POST"_method)
([](const crow::request &req) {
    if (req.method == crow::HTTPMethod::POST) {
        return crow::response(201, "created");
    }
    return crow::response("user list");
});

Handler

Um handler pode receber zero ou mais argumentos. O primeiro argumento pode ser const crow::request& para aceder aos headers e ao body; o segundo pode ser crow::response& se quiser escrever a resposta incrementalmente e chamar você próprio res.end().

Response

Devolva uma std::string para o body, ou uma crow::response quando precisar de definir o status code ou headers explicitamente:

return crow::response(404, "not found");

Rotas catchall

Use CROW_CATCHALL_ROUTE(app) para definir um fallback que corre sempre que nenhuma outra rota corresponde. O site de docs que está a ler agora usa uma para resolver paths desconhecidos contra um page index.

CROW_CATCHALL_ROUTE(app)([](const crow::request &req) {
    return crow::response(404, "no such page: " + req.url);
});
