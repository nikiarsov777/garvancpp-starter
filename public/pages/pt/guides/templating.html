Templates (Mustache)

Garvan expõe a implementação mustache do Crow. O modelo é deliberadamente simples: um ficheiro de template mais um objeto context é igual a HTML renderizado.

Componentes

Cada render envolve duas peças:

  • Page — um ficheiro em disco, carregado num crow::mustache::template_t.
  • Context — um crow::mustache::context (alias para crow::json::wvalue) que transporta os valores referenciados pelas tags do template.

Page

Os templates vivem sob um diretório base. Defina-o uma vez no arranque:

crow::mustache::set_global_base("public/");

Depois carregue ficheiros relativos a essa base:

auto page = crow::mustache::load("welcome.html");
auto text = crow::mustache::load_text("static_snippet.html"); // sem parse

O loader sanitiza o path; se realmente precisar de contornar isso (normalmente não precisa), use load_unsafe.

Context

Construa um context com quaisquer dados que a página precise:

crow::mustache::context ctx;
ctx["title"]   = "Welcome";
ctx["user"]    = "Ada";
ctx["items"]   = crow::json::wvalue::list({ "one", "two", "three" });
ctx["greet"]   = [](std::string) { return std::string("Hello there!"); };

Lambdas são permitidas e podem elas próprias devolver strings contendo tags mustache — o engine continua a fazer parse.

Partials

Reutilize fragmentos com a sintaxe {{> partial.html }}. O path é novamente relativo ao global base. O site de docs que está a ler usa partials para o top nav, sidebar, TOC e footer.

<body>
    {{> topnav.html }}
    <main>{{& content}}</main>
    {{> footer.html }}
</body>

Devolver um template

Renderize a página com o context e devolva o resultado:

CROW_ROUTE(app, "/welcome/<string>")([](std::string name) {
    auto page = crow::mustache::load("welcome.html");
    crow::mustache::context ctx;
    ctx["user"] = name;
    return page.render(ctx);
});

page.render(ctx) devolve um crow::returnable com Content-Type definido para text/html. Use render_string(ctx) se preferir ter uma std::string simples — por exemplo quando quiser embeber o resultado dentro de outro template.

Dica

Se o seu template precisar de incluir {{ literais (por exemplo um exemplo de código para esta própria página), escape-os com as entidades HTML &#123;&#123;.
