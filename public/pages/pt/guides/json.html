JSON

Garvan lê JSON através de crow::json::rvalue e escreve-o através de crow::json::wvalue. Há também um wrapper fino JsonValue no diretório tools para uso fora de request handlers.

Ler JSON

Faça parse do body de um pedido recebido e aceda a campos por chave:

CROW_ROUTE(app, "/api/echo")
    .methods("POST"_method)
([](const crow::request &req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "invalid json");

    std::string name = body["name"].s();
    int         age  = body["age"].i();
    return crow::response("hello " + name);
});

load devolve um valor falsy quando o parse falha, portanto verifique sempre antes de aceder a campos.

Escrever JSON

Construa um wvalue e devolva-o; Garvan define Content-Type: application/json automaticamente.

CROW_ROUTE(app, "/api/user")([] {
    crow::json::wvalue out;
    out["id"]      = 42;
    out["name"]    = "Ada";
    out["roles"]   = crow::json::wvalue::list({ "admin", "editor" });
    return out;
});

JsonValue do Garvan

JsonValue (alias json dentro dos route headers) é um wrapper fino que adiciona algumas conveniências para uso dentro de serviços. O UserMysqlController no starter incluído, por exemplo, devolve um JsonValue do seu método index().

#include "tools/JsonValue.h"
using json = JsonValue;

json users;
users.append({ {"id", 1}, {"name", "Ada"} });
users.append({ {"id", 2}, {"name", "Bo"} });
return users;
