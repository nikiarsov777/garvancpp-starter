Multipart

Os browsers enviam multipart/form-data quando um formulário contém inputs de ficheiro. Garvan faz parse destes pedidos através de crow::multipart::message.

Ler multipart

CROW_ROUTE(app, "/upload")
    .methods("POST"_method)
([](const crow::request &req) {
    crow::multipart::message msg(req);
    for (const auto &part : msg.parts) {
        const std::string &name = part.headers.at("Content-Disposition").params.at("name");
        CROW_LOG_INFO << name << " = " << part.body.substr(0, 64);
    }
    return crow::response(200, "received");
});

Uploads de ficheiro

O body de cada part contém bytes crus; escreva-o para disco:

if (part.headers.at("Content-Disposition").params.count("filename")) {
    std::ofstream out("/tmp/" + part.headers.at("Content-Disposition").params.at("filename"),
                      std::ios::binary);
    out << part.body;
}
Aviso

Nunca confie no filename fornecido pelo cliente. Retire separadores de path e valide contra uma allow-list antes de escrever para disco.
