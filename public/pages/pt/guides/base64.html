Base64

Os helpers Base64 vêm incluídos em crow::utility. Use-os para headers de HTTP basic auth, imagens embebidas, cookies assinados e tarefas semelhantes.

Codificar

#include "crow/utility.h"

std::string encoded = crow::utility::base64encode("Ada Lovelace", 12);
// encoded == "QWRhIExvdmVsYWNl"

Descodificar

std::string decoded = crow::utility::base64decode(encoded, encoded.size());

Ambas as funções são puras e alocam; tudo bem chamá-las dentro de handlers mas use um arena allocator se processar megabytes por pedido.
