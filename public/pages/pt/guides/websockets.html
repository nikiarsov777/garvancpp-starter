WebSockets

Os WebSockets dão-lhe canais bidirecionais e de baixa latência na mesma porta das suas routes HTTP. Garvan expõe a API WebSocket do Crow sem alterações.

Definir uma route websocket

CROW_WEBSOCKET_ROUTE(app, "/ws")
    .onopen([&](crow::websocket::connection &conn) {
        CROW_LOG_INFO << "client connected: " << &conn;
    })
    .onmessage([&](crow::websocket::connection &conn,
                    const std::string &data, bool is_binary) {
        conn.send_text("you said: " + data);
    })
    .onclose([&](crow::websocket::connection &conn, const std::string &reason, uint16_t code) {
        CROW_LOG_INFO << "client gone: " << reason;
    });

Eventos de conexão

Normalmente vai querer três handlers: onopen para acompanhar novas ligações, onmessage para frames recebidos, e onclose para limpar o estado. Guarde as ligações num container thread-safe se precisar de fazer broadcast.
