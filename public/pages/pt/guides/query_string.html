Strings de consulta

Tudo o que vem depois do ? num URL é parseado automaticamente. Aceda a isso via req.url_params.

Uso básico

CROW_ROUTE(app, "/search")([](const crow::request &req) {
    const char *q = req.url_params.get("q");
    if (!q) return crow::response(400, "missing q");
    return crow::response("you searched for: " + std::string(q));
});

get() devolve um const char* ou nullptr quando a chave está ausente — verifique sempre antes de dereferenciar.

Múltiplos valores

As listas escrevem-se como ?tag=a&tag=b:

auto tags = req.url_params.get_list("tag");
for (const auto &t : tags) CROW_LOG_INFO << "tag: " << t;

Para bodies application/x-www-form-urlencoded (típico para formulários HTML), chame req.get_body_params() — a API é idêntica.
