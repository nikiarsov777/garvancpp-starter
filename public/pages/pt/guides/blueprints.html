Blueprints

Um blueprint é um grupo de rotas que partilham um prefixo URL, uma base de templates ou um diretório estático. São úteis para dividir uma app grande em módulos — por exemplo um blueprint por versão de API.

Criar um blueprint

crow::Blueprint api("api/v1", "static_v1", "templates_v1");

CROW_BP_ROUTE(api, "/users")([] {
    return "v1 users";
});

Montar na app

app.register_blueprint(api);

O prefixo do blueprint é adicionado ao início de cada rota dentro dele, portanto o handler acima responde a GET /api/v1/users.
