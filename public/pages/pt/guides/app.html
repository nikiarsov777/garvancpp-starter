App

Uma app Garvan é o objeto que liga o servidor HTTP, o router, o logger e quaisquer middlewares registados. Vai ver uma em cada projeto.

SimpleApp

A escolha mais comum é crow::SimpleApp. Não tem middlewares ligados ao nível da aplicação — apenas routes.

crow::SimpleApp app;
CROW_ROUTE(app, "/")([] { return "ok"; });
app.port(9090).run();

App com middleware

Quando precisar de preocupações a nível de pedido (auth, sessões, CORS, etc.), use crow::App<M1, M2, ...>. Os middlewares são compostos da esquerda para a direita e desenrolados em compile time.

struct AuthMW { struct context {}; void before_handle(...) {} void after_handle(...) {} };

crow::App<AuthMW> app;

Encadeamento de métodos

Os métodos de configuração são encadeáveis, o que mantém o entry point legível:

app.bindaddr("0.0.0.0")
   .port(9090)
   .multithreaded()
   .run();

Executar assincronamente

run() bloqueia o thread que chama. Se precisar de continuar a fazer outro trabalho, capture o handle devolvido por run_async() — deixe a variável sair de scope e o servidor desliga.

auto handle = app.port(9090).run_async();
// ... outro trabalho ...
app.stop();
