Garvan C++

Un framework web C++ rápido y fácil de usar. Garvan extiende Crow con un ORM, migraciones, una capa modelo/controlador/servicio y una caja de herramientas de línea de comandos — para que puedas entregar servicios HTTP y WebSocket sin salir de C++.
