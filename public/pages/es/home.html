Corriendo en 8 líneas

Define una ruta, devuelve un string, corre la app. Garvan no estorba.

#include "crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([]{
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}
CROW_ROUTE(app, "/api/users/<int>")
([](int id) {
    crow::json::wvalue user;
    user["id"]    = id;
    user["name"]  = "Ada";
    user["email"] = "ada@example.com";
    return user;
});

JSON, fácil

Devuelve un crow::json::wvalue desde un handler y Garvan establece el Content-Type correcto por ti. El propio JsonValue de Garvan envuelve las mismas primitivas para uso dentro de servicios y modelos.

Un ORM que se siente familiar

Un query builder fluido escribe el SQL para cualquiera de los backends soportados. Los modelos extienden OModel y exponen find(), where() y relaciones.

auto users = db.table("users")
    .where("active", "=", 1)
    .order_by("created_at", "desc")
    .limit(20)
    .get();
