Tu primera aplicación

El programa Garvan más pequeño posible son solo unas pocas líneas de C++. Vamos a repasar qué hace cada parte.

1. Include

Empieza con un main.cpp vacío e incluye el header Crow que trae Garvan:

#include "vendors/Garvan/crow.h"

Este único header expone crow::SimpleApp, las macros de routing, los tipos de valor JSON y el motor de templates mustache.

2. Declaración de la app

Declara una aplicación Crow dentro de main():

int main()
{
    crow::SimpleApp app;
}

SimpleApp contiene el servidor HTTP, el router y el logger. Usa crow::App<M1, M2, ...> cuando necesites middlewares a nivel de aplicación — ver la guía de middleware.

3. Añadir routes

Un route asocia un patrón URL con un handler. La macro CROW_ROUTE es la forma más común:

CROW_ROUTE(app, "/")([] {
    return "Hello from Garvan!";
});

La lambda se llama cuando un cliente pide GET /. Devolver un std::string lo envía de vuelta como cuerpo de la respuesta.

4. Ejecutar

Elige un puerto y arranca el servidor:

app.port(9090).multithreaded().run();

multithreaded() le dice a Crow que use un worker por core CPU. run() bloquea hasta que el proceso termine; usa run_async() si necesitas hacer otro trabajo junto con el servidor.

Ejemplo completo

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([] {
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}

Compílalo y visita http://localhost:9090 — deberías ver el saludo en tu navegador.
