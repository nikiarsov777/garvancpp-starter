Una página web simple

Devolver una cadena plana está bien para pruebas, pero la mayoría de las aplicaciones necesitan HTML real. Garvan usa el motor mustache de Crow para templating — renderemos una página desde disco.

Página estática

Crea public/fancypage.html:

<!DOCTYPE html>
<html>
<body>
    <p>Hello World!</p>
</body>
</html>

Ahora dile a mustache dónde buscar templates y carga el archivo desde un handler:

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;
    crow::mustache::set_global_base("public/");

    CROW_ROUTE(app, "/")([] {
        return crow::mustache::load_text("fancypage.html");
    });

    app.port(9090).multithreaded().run();
}

load_text lee el archivo sin parsear tags mustache, así que es la opción más rápida para HTML puramente estático.

Página con una variable

Para inyectar datos, cambia de load_text a load, construye un contexto y renderiza. Actualiza el template:

<!DOCTYPE html>
<html>
<body>
    <p>Hello {{name}}!</p>
</body>
</html>

Y el route:

CROW_ROUTE(app, "/<string>")([](std::string name) {
    auto page = crow::mustache::load("fancypage.html");
    crow::mustache::context ctx;
    ctx["name"] = name;
    return page.render(ctx);
});

Visitar /Ada ahora mostrará Hello Ada!. El contexto puede contener strings, números, listas e incluso lambdas — ver la guía de templating para el conjunto completo de features mustache que Crow implementa.
