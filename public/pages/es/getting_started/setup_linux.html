Instalación en Linux

Esta página te guía por la instalación de Garvan y la compilación de tu primer ejecutable en una máquina Linux.

Requisitos

  • Un compilador C++ con soporte C++23 (GCC 14+ o Clang 18+).
  • CMake 3.20 o posterior.
  • Headers de desarrollo de Asio (1.28 o posterior).
  • libpq, libmysqlcppconn, libmongoc, libsqlite3, libmonetdb-mapi
  • libcurl — transporte SMTP para AppJobs::SendTestMail; también usado por los runtime verbs de kalpasan.
  • Opcional: OpenSSL para HTTPS, zlib para compresión.
Nota

El libgarvan.a incluido en vendors/Garvan/ ya enlaza Crow internamente, así que solo necesitas las librerías del sistema listadas arriba.

Instalar libgarvan

La vía más rápida es clonar el repositorio starter, que ya trae libgarvan.a, los headers de Crow y un CMakeLists.txt funcional:

git clone https://github.com/nikiarsov777/garvan-starter.git my-app
cd my-app

En Debian/Ubuntu puedes instalar los drivers de BD de una vez:

sudo apt update
sudo apt install -y \
    build-essential cmake \
    libasio-dev libssl-dev zlib1g-dev \
    libcurl4-openssl-dev \
    libpqxx-dev libmysqlcppconn-dev libsqlite3-dev \
    libmongoc-dev libbson-dev
libcurl auto-linked

El CMakeLists.txt del starter recoge libcurl via find_package(CURL REQUIRED) y enlaza CURL::libcurl en app_bin. No hace falta configuración manual una vez instalado el paquete.

Compilar desde código fuente

Si quieres compilar el propio Garvan (en vez de usar el archive incluido), clona el árbol de código y ejecuta CMake:

git clone https://github.com/nikiarsov777/garvancpp-starter.git
cd garvan
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build

Compilar tu proyecto

Añade lo siguiente al CMakeLists.txt de tu proyecto:

cmake_minimum_required(VERSION 3.20)
project(MyApp CXX)
set(CMAKE_CXX_STANDARD 23)

add_executable(my_app main.cpp)

target_include_directories(my_app PRIVATE
    vendors/Garvan
    vendors/Garvan/include
)

target_link_libraries(my_app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/vendors/Garvan/libgarvan.a
    pthread
)

Y compila:

cmake -S . -B build
cmake --build build
./build/my_app
