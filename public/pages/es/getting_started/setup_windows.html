Instalación en Windows

Garvan compila en Windows con MSVC 2019/2022 o MinGW-w64. El workflow más simple usa vcpkg para las dependencias.

Requisitos

  • Visual Studio 2022 (17.5+) con el workload «Desktop development with C++» — necesario para C++23.
  • CMake 3.20 (incluido con Visual Studio).
  • vcpkg o binarios pre-construidos para Asio, OpenSSL, libcurl y clientes de BD.

Usando vcpkg

git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install asio openssl zlib curl libpqxx sqlite3

Compilar con MSVC

Configura tu proyecto con el toolchain de vcpkg:

cmake -S . -B build ^
    -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
Advertencia

Garvan actualmente no incluye un libgarvan.lib precompilado para MSVC. En Windows debes construir Garvan desde código fuente para que el ABI C++ coincida con tu toolchain.
