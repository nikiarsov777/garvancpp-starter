Instalación en macOS

Construir apps Garvan en macOS funciona igual que en Linux — el libgarvan.a incluido es universal, solo necesitas instalar algunas librerías del sistema.

Requisitos

  • Xcode command line tools (xcode-select --install).
  • Un compilador C++ con soporte C++23 (Apple Clang de Xcode 16+ o LLVM Clang 18+ de Homebrew).
  • CMake 3.20 o posterior.
  • Headers de Asio.
  • libcurl (incluido en macOS; el curl de Homebrew es una opción más reciente).

Usando Homebrew

La vía más fácil es Homebrew. Instala las herramientas de build y los drivers de BD que necesites:

brew install cmake asio openssl@3 curl
brew install libpq mysql-connector-c++ mongo-cxx-driver sqlite
# Para C++23: instala un toolchain más nuevo si Apple Clang es viejo
brew install llvm@18

Compilar tu proyecto

Apunta CMake a los prefijos Homebrew para OpenSSL:

cmake -S . -B build \
    -DOPENSSL_ROOT_DIR=$(brew --prefix openssl@3) \
    -DCMAKE_PREFIX_PATH=$(brew --prefix)
cmake --build build
Consejo

En Mac con Apple Silicon, asegúrate de que todas las dependencias sean builds arm64 — mezclar Homebrew x86_64 con arm64 fallará en el link time.
