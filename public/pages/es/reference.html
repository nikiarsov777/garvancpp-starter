Referencia de API

Esta página enlaza a la referencia de API generada para Garvan y Crow. El framework apunta a C++23 (GCC 14+ / Clang 18+). La referencia se produce con Doxygen a partir de comentarios en los headers del árbol de código.

Acerca

La referencia cubre dos capas:

  • Garvan — las clases base model/controller/service, el ORM builder, el migration runner y las utilidades bajo vendors/Garvan/include/.
  • Crow — el servidor HTTP subyacente, router, JSON, mustache, multipart y subsistemas websocket.

Namespaces

  • Garvan — clases del framework (BaseContoller, BaseService, Builder, Migration, MigrationRunner).
  • ORM — la base OModel y tipos relacionados.
  • crow — todo desde upstream Crow: SimpleApp, App<...>, request, response, json::rvalue, json::wvalue, mustache::template_t.
Estado

La salida de Doxygen aún no está conectada a este sitio. Mientras tanto, consulta directamente los headers en vendors/Garvan/include/ y vendors/Garvan/crow/.
