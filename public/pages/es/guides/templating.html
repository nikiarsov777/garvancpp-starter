Plantillas (Mustache)

Garvan expone la implementación mustache de Crow. El modelo es deliberadamente simple: un archivo de plantilla más un objeto context igual a HTML renderizado.

Componentes

Cada render involucra dos piezas:

  • Page — un archivo en disco, cargado en un crow::mustache::template_t.
  • Context — un crow::mustache::context (alias para crow::json::wvalue) que lleva los valores referenciados por los tags de la plantilla.

Page

Las plantillas viven bajo un directorio base. Establécelo una vez al arranque:

crow::mustache::set_global_base("public/");

Luego carga archivos relativos a esa base:

auto page = crow::mustache::load("welcome.html");
auto text = crow::mustache::load_text("static_snippet.html"); // sin parseo

El loader sanitiza el path; si realmente necesitas saltártelo (normalmente no), usa load_unsafe.

Context

Construye un context con los datos que la página necesite:

crow::mustache::context ctx;
ctx["title"]   = "Welcome";
ctx["user"]    = "Ada";
ctx["items"]   = crow::json::wvalue::list({ "one", "two", "three" });
ctx["greet"]   = [](std::string) { return std::string("Hello there!"); };

Se permiten lambdas y pueden ellas mismas devolver strings que contengan tags mustache — el engine sigue parseando.

Parciales

Reutiliza fragmentos con la sintaxis {{> partial.html }}. El path es de nuevo relativo al global base. El sitio de docs que estás leyendo usa parciales para el top nav, sidebar, TOC y footer.

<body>
    {{> topnav.html }}
    <main>{{& content}}</main>
    {{> footer.html }}
</body>

Devolver una plantilla

Renderiza la página con el context y devuelve el resultado:

CROW_ROUTE(app, "/welcome/<string>")([](std::string name) {
    auto page = crow::mustache::load("welcome.html");
    crow::mustache::context ctx;
    ctx["user"] = name;
    return page.render(ctx);
});

page.render(ctx) devuelve un crow::returnable con Content-Type establecido a text/html. Usa render_string(ctx) si prefieres tener un std::string plano — por ejemplo cuando quieres embeber el resultado dentro de otra plantilla.

Consejo

Si tu plantilla necesita incluir {{ literales (por ejemplo un ejemplo de código para esta misma página), escápalos con las entidades HTML &#123;&#123;.
