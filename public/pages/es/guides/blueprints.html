Blueprints

Un blueprint es un grupo de routes que comparten un prefijo URL, una base de plantillas o un directorio estático. Son útiles para dividir una app grande en módulos — por ejemplo un blueprint por versión de API.

Crear un blueprint

crow::Blueprint api("api/v1", "static_v1", "templates_v1");

CROW_BP_ROUTE(api, "/users")([] {
    return "v1 users";
});

Montar en la app

app.register_blueprint(api);

El prefijo del blueprint se antepone a cada route dentro de él, así que el handler de arriba responde a GET /api/v1/users.
