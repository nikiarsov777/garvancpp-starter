WebSockets

Los WebSockets te dan canales bidireccionales de baja latencia en el mismo puerto que tus routes HTTP. Garvan expone la API de WebSocket de Crow sin cambios.

Definir una route websocket

CROW_WEBSOCKET_ROUTE(app, "/ws")
    .onopen([&](crow::websocket::connection &conn) {
        CROW_LOG_INFO << "client connected: " << &conn;
    })
    .onmessage([&](crow::websocket::connection &conn,
                    const std::string &data, bool is_binary) {
        conn.send_text("you said: " + data);
    })
    .onclose([&](crow::websocket::connection &conn, const std::string &reason, uint16_t code) {
        CROW_LOG_INFO << "client gone: " << reason;
    });

Eventos de conexión

Normalmente querrás tres handlers: onopen para trackear nuevas conexiones, onmessage para frames entrantes, y onclose para limpiar el estado. Guarda las conexiones en un contenedor thread-safe si necesitas broadcast.
