Cadenas de consulta

Todo lo que va después del ? en una URL se parsea automáticamente. Accede a ello vía req.url_params.

Uso básico

CROW_ROUTE(app, "/search")([](const crow::request &req) {
    const char *q = req.url_params.get("q");
    if (!q) return crow::response(400, "missing q");
    return crow::response("you searched for: " + std::string(q));
});

get() devuelve un const char* o nullptr cuando la clave está ausente — comprueba siempre antes de dereferenciar.

Múltiples valores

Las listas se escriben como ?tag=a&tag=b:

auto tags = req.url_params.get_list("tag");
for (const auto &t : tags) CROW_LOG_INFO << "tag: " << t;

Para bodies application/x-www-form-urlencoded (típico para formularios HTML), llama a req.get_body_params() — la API es idéntica.
