Multipart

Los navegadores envían multipart/form-data cuando un formulario contiene inputs de archivo. Garvan parsea estas peticiones a través de crow::multipart::message.

Leer multipart

CROW_ROUTE(app, "/upload")
    .methods("POST"_method)
([](const crow::request &req) {
    crow::multipart::message msg(req);
    for (const auto &part : msg.parts) {
        const std::string &name = part.headers.at("Content-Disposition").params.at("name");
        CROW_LOG_INFO << name << " = " << part.body.substr(0, 64);
    }
    return crow::response(200, "received");
});

Subidas de archivo

El body de cada part contiene bytes crudos; escríbelo a disco:

if (part.headers.at("Content-Disposition").params.count("filename")) {
    std::ofstream out("/tmp/" + part.headers.at("Content-Disposition").params.at("filename"),
                      std::ios::binary);
    out << part.body;
}
Advertencia

Nunca confíes en el filename proporcionado por el cliente. Elimina separadores de path y valida contra un allow-list antes de escribir a disco.
