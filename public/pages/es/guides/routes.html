Rutas

Una ruta enlaza un método HTTP + patrón URL a un handler. Garvan hereda el router compile-time de Crow, que construye un árbol de decisión a partir de tus definiciones de ruta — los lookups son O(log n) y no hay regex involucrada.

La macro CROW_ROUTE

La forma canónica de declarar una ruta:

CROW_ROUTE(app, "/hello")([] {
    return "hi";
});

También puedes usar app.route_dynamic("/hello") si necesitas construir paths en runtime, pero la forma macro es preferida porque se comprueba en compile time.

Parámetros URL

Coloca parámetros en corchetes angulares y acéptalos como argumentos de tu handler. Los tipos soportados son int, uint, double, string y path:

CROW_ROUTE(app, "/users/<int>")([](int id) {
    return std::to_string(id);
});

CROW_ROUTE(app, "/files/<path>")([](std::string rest) {
    return "you requested: " + rest;
});

Métodos HTTP

Las rutas por defecto son GET. Usa .methods(...) para registrar verbos adicionales:

CROW_ROUTE(app, "/users")
    .methods("GET"_method, "POST"_method)
([](const crow::request &req) {
    if (req.method == crow::HTTPMethod::POST) {
        return crow::response(201, "created");
    }
    return crow::response("user list");
});

Handler

Un handler puede tomar cero o más argumentos. El primer argumento puede ser const crow::request& para acceder a headers y el body; el segundo puede ser crow::response& si quieres escribir la respuesta incrementalmente y llamar tú mismo a res.end().

Response

Devuelve un std::string para el body, o un crow::response cuando necesites establecer el status code o headers explícitamente:

return crow::response(404, "not found");

Rutas catchall

Usa CROW_CATCHALL_ROUTE(app) para definir un fallback que corre cuando ninguna otra ruta coincide. El sitio de docs que estás leyendo ahora usa uno para resolver paths desconocidos contra un page index.

CROW_CATCHALL_ROUTE(app)([](const crow::request &req) {
    return crow::response(404, "no such page: " + req.url);
});
