JSON

Garvan lee JSON a través de crow::json::rvalue y lo escribe a través de crow::json::wvalue. También hay un wrapper delgado JsonValue en el directorio tools para uso fuera de request handlers.

Leer JSON

Parsea el body de un request entrante y accede a campos por clave:

CROW_ROUTE(app, "/api/echo")
    .methods("POST"_method)
([](const crow::request &req) {
    auto body = crow::json::load(req.body);
    if (!body) return crow::response(400, "invalid json");

    std::string name = body["name"].s();
    int         age  = body["age"].i();
    return crow::response("hello " + name);
});

load devuelve un valor falsy cuando el parseo falla, así que siempre comprueba antes de acceder a campos.

Escribir JSON

Construye un wvalue y devuélvelo; Garvan establece Content-Type: application/json automáticamente.

CROW_ROUTE(app, "/api/user")([] {
    crow::json::wvalue out;
    out["id"]      = 42;
    out["name"]    = "Ada";
    out["roles"]   = crow::json::wvalue::list({ "admin", "editor" });
    return out;
});

JsonValue de Garvan

JsonValue (alias json dentro de los route headers) es un wrapper delgado que añade algunas conveniencias para uso dentro de services. El UserMysqlController del starter incluido, por ejemplo, devuelve un JsonValue desde su método index().

#include "tools/JsonValue.h"
using json = JsonValue;

json users;
users.append({ {"id", 1}, {"name", "Ada"} });
users.append({ {"id", 2}, {"name", "Bo"} });
return users;
