App

Una app Garvan es el objeto que une el servidor HTTP, el router, el logger y cualquier middleware registrado. La verás en todos los proyectos.

SimpleApp

La elección más común es crow::SimpleApp. No lleva middlewares a nivel de aplicación — solo routes.

crow::SimpleApp app;
CROW_ROUTE(app, "/")([] { return "ok"; });
app.port(9090).run();

App con middleware

Cuando necesites preocupaciones a nivel de request (auth, sesiones, CORS, etc.), usa crow::App<M1, M2, ...>. Los middlewares se componen de izquierda a derecha y se desenrollan en compile time.

struct AuthMW { struct context {}; void before_handle(...) {} void after_handle(...) {} };

crow::App<AuthMW> app;

Encadenamiento de métodos

Los métodos de configuración son encadenables, lo que mantiene el entry point legible:

app.bindaddr("0.0.0.0")
   .port(9090)
   .multithreaded()
   .run();

Ejecutar asincrónicamente

run() bloquea el hilo que llama. Si necesitas seguir haciendo otro trabajo, captura el handle devuelto por run_async() — deja que la variable salga de scope y el servidor apagará.

auto handle = app.port(9090).run_async();
// ... otro trabajo ...
app.stop();
