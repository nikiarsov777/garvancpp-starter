Controladores

Un controller conecta rutas HTTP con la capa de datos. Cada uno extiende Garvan::BaseContoller y expone las cinco acciones REST que esperarías.

BaseController

La clase base declara un contrato pequeño:

class BaseContoller : public Helper
{
public:
    virtual json index() = 0;          // GET /resource
    json         create(json model);   // POST /resource
    json         read(string id);      // GET /resource/:id
    json         update(json model);   // PUT /resource/:id
    void         erease();             // DELETE /resource/:id
    json         getById(string id);
};

Solo index() es puro virtual — todo lo demás tiene una implementación por defecto que puedes sobrescribir por recurso.

Acciones REST

Un controller de recurso típico:

// app/controllers/api/PostController.h
#pragma once
#include "controller/BaseContoller.h"
#include "../../services/PostService.h"

class PostController : public Garvan::BaseContoller
{
public:
    json index() override {
        PostService svc;
        return svc.index();
    }
};

Conéctalo a una ruta en routes/ApiRoutes.cpp:

CROW_ROUTE(app, "/api/posts")([] {
    PostController c;
    return jsonresponse{ c.index() };
});
