Correo (SMTP)

El starter incluye un job real y enviable: AppJobs::SendTestMail. Su handle() (app/jobs/SendTestMail.cpp:58) abre una sesión SMTP con libcurl, construye un mensaje RFC 822 con cuerpo HTML, autentica, envía y registra el resultado. Todo lo controla el bloque MAIL_* de .env.

Configuración MAIL_*

MAIL_DRIVER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=465
MAIL_USERNAME="user@example.com"
MAIL_PASSWORD="app-password"
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="user@example.com"
MAIL_FROM_NAME="Your App"
MAIL_AUTHENTICATION=plain
ClavePropósito
MAIL_HOST, MAIL_PORTEndpoint SMTP.
MAIL_USERNAME, MAIL_PASSWORDCredenciales (libcurl auto-negocia el mecanismo AUTH).
MAIL_ENCRYPTIONtls, ssl o smtps. ssl/smtps fuerzan TLS implícito sin importar el puerto.
MAIL_FROM_ADDRESS, MAIL_FROM_NAMEEnvelope sender + display name en From:.
MAIL_AUTHENTICATIONInformativo; libcurl auto-negocia.

Los valores pueden ir entre "..."; el job quita las comillas circundantes antes de usarlos.

Puertos y encryption

  • 465 → TLS implícito (smtps://). Handshake antes del banner SMTP.
  • 587 → STARTTLS. El job usa smtp:// y fuerza TLS via CURLUSESSL_ALL.
  • Cualquier otro puerto con MAIL_ENCRYPTION=ssl o smtps → TLS implícito forzado.

Contenido HTML

El header RFC 822 está fijado a Content-Type: text/html; charset=UTF-8 con 8-bit CTE, así que el campo body puede contener HTML arbitrario incluyendo texto UTF-8:

curl "http://localhost:9090/api/jobs/send-mail?to=you@x.com&subject=Hi&body=<h1>Hello</h1><p><b>Bold</b></p>"

Debug del diálogo SMTP

Si el envío tiene éxito según libcurl pero nunca llega al inbox (spam, greylist, rechazo silencioso), activa el modo verbose temporalmente:

// app/jobs/SendTestMail.cpp
curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);   // cambia 0L a 1L

Rebuild, restart, retry. Obtienes el TLS handshake completo más el diálogo SMTP en el stdout del servidor — EHLO, AUTH, MAIL FROM, RCPT TO, DATA y el final 250 2.0.0 Ok: queued as ....

No hagas commit del cambio

Los logs SMTP verbose filtran headers sensibles y dañan el rendimiento. Vuelve a 0L antes de commit.

Ejemplos con providers

Gmail (app password, port 465):

MAIL_HOST=smtp.gmail.com
MAIL_PORT=465
MAIL_USERNAME=you@gmail.com
MAIL_PASSWORD=xxxx-xxxx-xxxx-xxxx    # app password, no la contraseña de la cuenta
MAIL_ENCRYPTION=ssl
MAIL_FROM_ADDRESS=you@gmail.com

SendGrid (API relay, port 587 STARTTLS):

MAIL_HOST=smtp.sendgrid.net
MAIL_PORT=587
MAIL_USERNAME=apikey
MAIL_PASSWORD=SG.xxxxxxxxxxxxxxxxxxxxxxxx
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=you@yourdomain.com

SMTP personalizado (port 465):

MAIL_HOST=mail.your-host.com
MAIL_PORT=465
MAIL_USERNAME=info@yourdomain.com
MAIL_PASSWORD=your-mailbox-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=info@yourdomain.com
MAIL_FROM_NAME="Your Brand"
