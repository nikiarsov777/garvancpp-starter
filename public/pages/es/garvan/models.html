Modelos

Un modelo representa una tabla de la base de datos. Lleva metadatos (nombre de tabla, primary key, columnas) y hereda los métodos del query builder de ORM::OModel.

BaseModel

Coloca tus modelos bajo app/models/. Un modelo mínimo:

// app/models/Post.h
#pragma once
#include "orm/omodel.h"

class Post : public ORM::OModel
{
public:
    Post() {
        table          = "posts";
        primaryKey     = "id";
        public_columns  = {"id", "title", "body", "user_id", "created_at"};
        private_columns = {};
    }
};

Relaciones

Builder expone cuatro helpers de relación que OModel hereda:

  • hasOne(model, foreignKey, localKey)
  • hasMany(model, foreignKey, ownerKey)
  • belongsTo(model, foreignKey, ownerKey)
  • belongsToMany(model, pivotTable, foreignKey, ownerKey)

Cada uno programa un join que se resuelve al llamar get(). Reflejan la API de relaciones que puede que conozcas de Laravel.

User u;
auto posts = u.find(42).hasMany(Post{}, "user_id", "id").get();
