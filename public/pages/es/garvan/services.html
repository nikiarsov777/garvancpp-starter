Servicios

Los servicios están entre controllers y modelos. Contienen la lógica de negocio que no pertenece a ninguno — validación, operaciones multi-tabla, llamadas a APIs externas.

BaseService

La clase base refleja BaseContoller pero con todos los métodos virtual:

class BaseService : public Helper
{
public:
    virtual json index();
    virtual json create(json model);
    json         create(const crow::request &req); // conveniencia: parsea el body por ti
    virtual json read(string id);
    virtual json update(json model);
    virtual void erease();
    virtual json getById(string id);
};

Usar un servicio en un controller

Instancia el servicio dentro del método del controller, o inyéctalo por el constructor:

json PostController::index()
{
    PostService svc;
    auto posts = svc.index();

    // post-procesamiento: ocultar campos private, adjuntar metadata de paginación, etc.
    json out;
    out["data"]  = posts;
    out["count"] = posts.size();
    return out;
}

La capa de servicios también facilita el testing — los controllers se vuelven shims delgados y los servicios se pueden ejercitar sin arrancar el servidor HTTP.
