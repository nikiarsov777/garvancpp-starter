Utilidades

Tres pequeñas clases utilitarias viven bajo vendors/Garvan/include/tools/. Te las encontrarás mientras escribes controllers y services.

Helper

La clase Helper es la base tanto de BaseContoller como de BaseService. Proporciona métodos de conveniencia que no encajan en ningún otro lado — formateo de fechas, generación de slugs, construcción de respuestas.

#include "tools/Helper.h"

std::string slug = Helper::slug("Hello, World!"); // "hello-world"

JsonValue

Un wrapper sobre crow::json::wvalue con helpers para objetos y arrays anidados. Úsalo como tipo de retorno de los métodos de service y controller:

#include "tools/JsonValue.h"
using json = JsonValue;

json out;
out["status"] = "ok";
out["data"]   = json::Array();
out["data"].append({ {"id", 1}, {"name", "Ada"} });
return out;

Logger

Ya cubierto en la página Registro. Úsalo cuando quieras loggear algo desde un lugar donde el logger de Crow no sea alcanzable.
