Query proxies (2026-09-26)

Model now proxies the full expanded query surface directly onto model instances; there is no need to drop into getBuilder() for the common cases. Every method below has an identical counterpart on TypedQuery<T> for chained composition.

  • where(field, op, nullptr_t) and orWhere(field, op, nullptr_t) — emit <col> IS [NOT] NULL inline (no bind).
  • orWhere(...) overloads mirror where(...): string / typed / nullptr_t.
  • whereIn / orWhereIn / whereNotIn / orWhereNotIn — each value binds as its own placeholder; empty list throws.
  • orderBy(col, dir) — asc|desc guard, column through sanitizeOrderBy allowlist.
  • orderByRaw(expr) — multi-column sorts and backend extensions (NULLS LAST / NULLS FIRST).
  • select(col) / selectAs(col, alias) / selectRaw(expr, alias="") — structured projection; non-empty projection beats public_columns and withPrivate().
  • withPrivate() — opts into SELECT <table>.*, including columns kept out of public_columns.
  • count() — COUNT(*) aggregate terminal; returns int64_t.
  • joinAs / leftJoinAs / rightJoinAs / innerJoinAs — <TYPE> JOIN <table> AS <alias>.
  • get(std::vector<std::string> cols) — per-query override of public_columns, useful when a JOIN needs columns from a table other than the model's own.
// Aliased self-JOIN + structured projection + COUNT
int64_t decided = Games::query<Games>()
    ->leftJoinAs("users", "w", "w.id", "=", "games.white_id")
    ->leftJoinAs("users", "b", "b.id", "=", "games.black_id")
    ->where("games.result", "IS NOT", nullptr)
    ->count();

// IS NULL, structured SELECT, ordering
auto pending = Invoice::query<Invoice>()
    ->select("invoices.id")
    ->selectAs("customers.name", "customer_name")
    ->leftJoin("customers", "customers.id", "invoices.customer_id")
    ->where("invoices.paid_at", "IS", nullptr)
    ->orderBy("invoices.due_at", "asc")
    ->get();

Model default client. The Model constructor default changed from "PSQL" to "": an empty client now delegates to DbFactory, which resolves the backend from the .env file. Explicit Model("PSQL") still works. See ORM » Query surface expansion for the full reference.
