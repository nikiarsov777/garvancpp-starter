Установка на macOS

Сборка Garvan приложений на macOS работает так же, как на Linux — встроенный libgarvan.a универсален, нужно только установить несколько системных библиотек.

Требования

  • Xcode command line tools (xcode-select --install).
  • C++ компилятор с поддержкой C++23 (Xcode 16+ Apple Clang или LLVM Clang 18+ из Homebrew).
  • CMake 3.20 или новее.
  • Asio headers.
  • libcurl (идёт с macOS; curl из Homebrew — более новая опция).

С Homebrew

Проще всего через Homebrew. Установите инструменты сборки и нужные драйверы БД:

brew install cmake asio openssl@3 curl
brew install libpq mysql-connector-c++ mongo-cxx-driver sqlite
# Для C++23: установите новее toolchain если Apple Clang старый
brew install llvm@18

Компиляция вашего проекта

Укажите CMake префиксы Homebrew для OpenSSL:

cmake -S . -B build \
    -DOPENSSL_ROOT_DIR=$(brew --prefix openssl@3) \
    -DCMAKE_PREFIX_PATH=$(brew --prefix)
cmake --build build
Совет

На Apple Silicon Mac убедитесь что все зависимости — arm64 сборки; смешивание x86_64 Homebrew с arm64 сломается при линковке.
