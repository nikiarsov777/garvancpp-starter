Ваше первое приложение

Минимальная Garvan программа — всего несколько строк C++. Пройдёмся по каждой части.

1. Include

Начните с пустого main.cpp и подключите Garvan-packaged Crow header:

#include "vendors/Garvan/crow.h"

Этот один header открывает crow::SimpleApp, routing макросы, JSON типы значений и mustache template engine.

2. Объявление приложения

Объявите Crow приложение внутри main():

int main()
{
    crow::SimpleApp app;
}

SimpleApp держит HTTP сервер, router и logger. Используйте crow::App<M1, M2, ...> если нужны middleware на уровне приложения — см. руководство по middleware.

3. Добавление routes

Route связывает URL шаблон с handler-ом. Макрос CROW_ROUTE — самый распространённый способ:

CROW_ROUTE(app, "/")([] {
    return "Hello from Garvan!";
});

Lambda вызывается при каждом клиентском запросе GET /. Возврат std::string отправляет её как response body.

4. Запуск

Выберите порт и стартуйте сервер:

app.port(9090).multithreaded().run();

multithreaded() говорит Crow использовать один worker на CPU core. run() блокирует пока процесс не завершится; используйте run_async() если нужно делать другую работу параллельно с сервером.

Полный пример

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([] {
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}

Соберите и откройте http://localhost:9090 — вы должны увидеть приветствие в браузере.
