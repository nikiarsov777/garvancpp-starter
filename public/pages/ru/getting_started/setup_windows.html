Установка на Windows

Garvan компилируется на Windows с MSVC 2019/2022 или MinGW-w64. Простейший workflow использует vcpkg для зависимостей.

Требования

  • Visual Studio 2022 (17.5+) с пакетом «Desktop development with C++» — необходим для C++23.
  • CMake 3.20 (входит в Visual Studio).
  • vcpkg или готовые binary для Asio, OpenSSL, libcurl и клиентов БД.

Используя vcpkg

git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install asio openssl zlib curl libpqxx sqlite3

Компиляция с MSVC

Конфигурируйте проект с vcpkg toolchain:

cmake -S . -B build ^
    -DCMAKE_TOOLCHAIN_FILE=/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
Внимание

Garvan сейчас не поставляет предкомпилированный libgarvan.lib для MSVC. На Windows соберите Garvan из исходников чтобы C++ ABI совпал с вашим toolchain.
