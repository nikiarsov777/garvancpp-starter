Установка на Linux

Эта страница проведёт вас через установку Garvan и компиляцию первого исполняемого файла на Linux машине.

Требования

  • C++ компилятор с поддержкой C++23 (GCC 14+ или Clang 18+).
  • CMake 3.20 или новее.
  • Asio development headers (1.28 или новее).
  • libpq, libmysqlcppconn, libmongoc, libsqlite3, libmonetdb-mapi
  • libcurl — SMTP транспорт для AppJobs::SendTestMail; также используется kalpasan runtime verbs.
  • Опционально: OpenSSL для HTTPS, zlib для сжатия.
Заметка

Встроенный libgarvan.a в vendors/Garvan/ уже линкует Crow внутренне, так что вам нужны только системные библиотеки выше.

Установка libgarvan

Быстрый путь — клонировать стартовое хранилище, которое уже содержит libgarvan.a, header-ы Crow и рабочий CMakeLists.txt:

git clone https://github.com/nikiarsov777/garvan-starter.git my-app
cd my-app

На Debian/Ubuntu можно установить драйверы БД одной командой:

sudo apt update
sudo apt install -y \
    build-essential cmake \
    libasio-dev libssl-dev zlib1g-dev \
    libcurl4-openssl-dev \
    libpqxx-dev libmysqlcppconn-dev libsqlite3-dev \
    libmongoc-dev libbson-dev
libcurl auto-linked

Starter'ский CMakeLists.txt подхватывает libcurl через find_package(CURL REQUIRED) и линкует CURL::libcurl в app_bin. Ручная настройка не требуется после установки пакета.

Сборка из исходного кода

Если хотите собрать сам Garvan (вместо использования готового архива), клонируйте дерево исходников и запустите CMake:

git clone https://github.com/nikiarsov777/garvancpp-starter.git
cd garvan
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build

Компиляция вашего проекта

Добавьте следующее в CMakeLists.txt вашего проекта:

cmake_minimum_required(VERSION 3.20)
project(MyApp CXX)
set(CMAKE_CXX_STANDARD 23)

add_executable(my_app main.cpp)

target_include_directories(my_app PRIVATE
    vendors/Garvan
    vendors/Garvan/include
)

target_link_libraries(my_app PRIVATE
    ${CMAKE_CURRENT_SOURCE_DIR}/vendors/Garvan/libgarvan.a
    pthread
)

Затем соберите:

cmake -S . -B build
cmake --build build
./build/my_app
