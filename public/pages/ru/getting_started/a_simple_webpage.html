Простая веб-страница

Возврат простой строки хорош для тестов, но большинство приложений нуждаются в реальном HTML. Garvan использует mustache engine Crow для template-ов — отрендерим страницу с диска.

Статическая страница

Создайте public/fancypage.html:

<!DOCTYPE html>
<html>
<body>
    <p>Hello World!</p>
</body>
</html>

Теперь скажите mustache где искать template-ы и загрузите файл из handler-а:

#include "vendors/Garvan/crow.h"

int main()
{
    crow::SimpleApp app;
    crow::mustache::set_global_base("public/");

    CROW_ROUTE(app, "/")([] {
        return crow::mustache::load_text("fancypage.html");
    });

    app.port(9090).multithreaded().run();
}

load_text читает файл без парсинга mustache тегов, поэтому это самая быстрая опция для чисто статического HTML.

Страница с переменной

Для инъекции данных переключитесь с load_text на load, постройте context и render. Обновите template:

<!DOCTYPE html>
<html>
<body>
    <p>Hello {{name}}!</p>
</body>
</html>

И route:

CROW_ROUTE(app, "/<string>")([](std::string name) {
    auto page = crow::mustache::load("fancypage.html");
    crow::mustache::context ctx;
    ctx["name"] = name;
    return page.render(ctx);
});

Посещение /Ada теперь покажет Hello Ada!. Context может содержать строки, числа, списки и даже lambda-ы — см. руководство по template-ам для полного набора mustache функций, которые Crow реализует.
