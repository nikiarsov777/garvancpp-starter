App

Garvan app — это объект, который связывает HTTP сервер, router, logger и любые зарегистрированные middleware вместе. Вы увидите его в каждом проекте.

SimpleApp

Самый частый выбор — crow::SimpleApp. Он не имеет middleware на уровне приложения — только routes.

crow::SimpleApp app;
CROW_ROUTE(app, "/")([] { return "ok"; });
app.port(9090).run();

App с middleware

Когда нужны request-wide заботы (auth, sessions, CORS и т.д.), используйте crow::App<M1, M2, ...>. Middleware комбинируются слева-направо и разворачиваются в compile time.

struct AuthMW { struct context {}; void before_handle(...) {} void after_handle(...) {} };

crow::App<AuthMW> app;

Method chaining

Методы конфигурации chainable, что делает entry point читаемым:

app.bindaddr("0.0.0.0")
   .port(9090)
   .multithreaded()
   .run();

Асинхронный запуск

run() блокирует вызывающий поток. Если нужно продолжать делать другую работу, захватите handle возвращаемый run_async() — когда переменная выйдет из scope, сервер shut down.

auto handle = app.port(9090).run_async();
// ... другая работа ...
app.stop();
