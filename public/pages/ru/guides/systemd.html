systemd сервис

Чтобы запускать ваш Garvan binary при boot, положите systemd unit файл в /etc/systemd/system/ и включите его.

Unit файл

[Unit]
Description=My Garvan app
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/srv/my-app
ExecStart=/srv/my-app/bin/app.bin
Restart=on-failure
RestartSec=5
EnvironmentFile=/srv/my-app/.env

[Install]
WantedBy=multi-user.target

Активация сервиса

sudo systemctl daemon-reload
sudo systemctl enable --now my-app.service
sudo journalctl -u my-app.service -f

Последняя команда tails логи — полезно пока настраиваете.
