WebSockets

WebSockets дают вам двунаправленные каналы с низкой задержкой на том же порту, что и ваши HTTP routes. Garvan выставляет WebSocket API Crow без изменений.

Определение websocket route

CROW_WEBSOCKET_ROUTE(app, "/ws")
    .onopen([&](crow::websocket::connection &conn) {
        CROW_LOG_INFO << "client connected: " << &conn;
    })
    .onmessage([&](crow::websocket::connection &conn,
                    const std::string &data, bool is_binary) {
        conn.send_text("you said: " + data);
    })
    .onclose([&](crow::websocket::connection &conn, const std::string &reason, uint16_t code) {
        CROW_LOG_INFO << "client gone: " << reason;
    });

События соединения

Обычно вам нужны три handler-а: onopen для отслеживания новых соединений, onmessage для входящих frames и onclose для очистки state. Храните соединения в thread-safe контейнере если нужен broadcast.
