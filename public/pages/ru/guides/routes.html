Маршруты

Route связывает HTTP метод + URL шаблон с handler-ом. Garvan наследует compile-time router Crow, который строит дерево решений из ваших route определений — поиск O(log n) и regex не участвует.

Макрос CROW_ROUTE

Каноничный способ объявить route:

CROW_ROUTE(app, "/hello")([] {
    return "hi";
});

Можно также использовать app.route_dynamic("/hello") если нужно строить пути в runtime, но макрос предпочтителен потому что проверяется в compile time.

URL параметры

Поместите параметры в угловые скобки и принимайте их как аргументы handler. Поддерживаемые типы: int, uint, double, string и path:

CROW_ROUTE(app, "/users/<int>")([](int id) {
    return std::to_string(id);
});

CROW_ROUTE(app, "/files/<path>")([](std::string rest) {
    return "you requested: " + rest;
});

HTTP методы

Routes по умолчанию GET. Используйте .methods(...) чтобы зарегистрировать дополнительные глаголы:

CROW_ROUTE(app, "/users")
    .methods("GET"_method, "POST"_method)
([](const crow::request &req) {
    if (req.method == crow::HTTPMethod::POST) {
        return crow::response(201, "created");
    }
    return crow::response("user list");
});

Handler

Handler может принимать ноль или больше аргументов. Первый может быть const crow::request& для доступа к headers и body; второй может быть crow::response& если хотите писать response инкрементально и сами вызывать res.end().

Response

Верните std::string как body, или crow::response когда нужно явно задать status code или headers:

return crow::response(404, "not found");

Catchall маршруты

Используйте CROW_CATCHALL_ROUTE(app) чтобы определить fallback, который запускается когда ни один другой route не совпадает. Docs сайт, который вы сейчас читаете, использует его для резолва неизвестных путей против page index.

CROW_CATCHALL_ROUTE(app)([](const crow::request &req) {
    return crow::response(404, "no such page: " + req.url);
});
