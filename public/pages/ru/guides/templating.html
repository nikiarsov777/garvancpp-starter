Шаблоны (Mustache)

Garvan выставляет реализацию mustache от Crow. Модель намеренно проста: файл шаблона плюс объект context равно отрендеренный HTML.

Компоненты

Каждый рендер вовлекает две части:

  • Page — файл на диске, загруженный в crow::mustache::template_t.
  • Context — crow::mustache::context (alias для crow::json::wvalue), несущий значения, на которые ссылаются теги шаблона.

Page

Шаблоны живут под базовой директорией. Установите её один раз при старте:

crow::mustache::set_global_base("public/");

Затем загружайте файлы относительно этой базы:

auto page = crow::mustache::load("welcome.html");
auto text = crow::mustache::load_text("static_snippet.html"); // без парсинга

Loader санитизирует путь; если вам совершенно нужно это обойти (обычно нет), используйте load_unsafe.

Context

Постройте context с любыми данными, которые нужны странице:

crow::mustache::context ctx;
ctx["title"]   = "Welcome";
ctx["user"]    = "Ada";
ctx["items"]   = crow::json::wvalue::list({ "one", "two", "three" });
ctx["greet"]   = [](std::string) { return std::string("Hello there!"); };

Lambda-ы разрешены и могут сами возвращать строки, содержащие mustache теги — engine продолжает парсить.

Партиалы

Переиспользуйте фрагменты синтаксисом {{> partial.html }}. Путь снова относительно global base. Docs сайт, который вы читаете, использует партиалы для top nav, sidebar, TOC и footer.

<body>
    {{> topnav.html }}
    <main>{{& content}}</main>
    {{> footer.html }}
</body>

Возврат шаблона

Отрендерьте page с context-ом и верните результат:

CROW_ROUTE(app, "/welcome/<string>")([](std::string name) {
    auto page = crow::mustache::load("welcome.html");
    crow::mustache::context ctx;
    ctx["user"] = name;
    return page.render(ctx);
});

page.render(ctx) возвращает crow::returnable с установленным Content-Type на text/html. Используйте render_string(ctx) если предпочитаете обычный std::string — например когда хотите встроить результат внутри другого шаблона.

Совет

Если шаблону нужно включить литеральные {{ (например образец кода для этой самой страницы), экранируйте их HTML entities &#123;&#123;.
