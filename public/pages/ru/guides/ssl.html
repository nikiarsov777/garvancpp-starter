SSL

Garvan поддерживает HTTPS через OpenSSL. Можно запустить сервер напрямую на TLS, или terminate на reverse proxy — см. руководство по proxies для последнего.

Активация SSL

SSL должен быть активирован в build time. Добавьте -DCROW_ENABLE_SSL к compiler flags и линкуйте с OpenSSL:

find_package(OpenSSL REQUIRED)
target_compile_definitions(app_bin PRIVATE CROW_ENABLE_SSL)
target_link_libraries(app_bin PRIVATE OpenSSL::SSL OpenSSL::Crypto)

Сертификаты

Укажите app на сертификат и private key:

app.bindaddr("0.0.0.0")
   .port(443)
   .ssl_file("certs/fullchain.pem", "certs/privkey.pem")
   .multithreaded()
   .run();
Совет

Если нужны только development сертификаты, openssl req -x509 -newkey rsa:2048 -nodes -keyout privkey.pem -out fullchain.pem -days 30 -subj /CN=localhost производит self-signed пару за секунды.
