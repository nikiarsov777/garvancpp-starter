Blueprints

Blueprint — группа routes, которые разделяют URL prefix, template base или static директорию. Удобны для разбиения большого app на модули — например один blueprint на API версию.

Создание blueprint

crow::Blueprint api("api/v1", "static_v1", "templates_v1");

CROW_BP_ROUTE(api, "/users")([] {
    return "v1 users";
});

Прикрепление к app

app.register_blueprint(api);

Prefix blueprint-а prepend-ится к каждому route внутри него, так что handler выше отвечает GET /api/v1/users.
