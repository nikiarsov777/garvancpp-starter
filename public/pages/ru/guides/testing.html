Написание тестов

Вы можете упражнять handlers напрямую без bind-инга на реальный порт. Crow позволяет вам вызывать handle() на synthetic request и инспектировать response.

Юнит-тесты

#include "crow.h"
#include "doctest.h"

TEST_CASE("hello returns greeting") {
    crow::SimpleApp app;
    CROW_ROUTE(app, "/")([] { return "hi"; });

    crow::request req;
    req.url = "/";
    crow::response res;
    app.handle(req, res);

    CHECK(res.code == 200);
    CHECK(res.body == "hi");
}

Интеграционные тесты

Для end-to-end покрытия запустите app с run_async() и хитайте его libcurl или любым HTTP клиентом:

auto handle = app.port(0).run_async();   // port 0 = auto-pick
auto port   = app.port();                  // узнайте bound port
// ... issue requests against http://localhost:port ...
app.stop();
