Логирование

Garvan поставляет два logging средства: встроенные CROW_LOG_* макросы Crow и небольшой helper класс Logger в vendors/Garvan/include/tools/Logger.h.

CROW_LOG_* макросы

Макросы Crow — stream-style и уважают global level threshold:

CROW_LOG_DEBUG    << "incoming request: " << req.url;
CROW_LOG_INFO     << "user " << user_id << " logged in";
CROW_LOG_WARNING  << "deprecated endpoint hit";
CROW_LOG_ERROR    << "db connection failed: " << ex.what();
CROW_LOG_CRITICAL << "out of memory";

Garvan Logger

Используйте Logger внутри service или model кода когда Crow app недоступен:

#include "tools/Logger.h"

Logger::info("indexing started");
Logger::error("could not open file: {}", path);

Уровни логирования

Установите threshold при старте:

crow::logger::setLogLevel(crow::LogLevel::Warning);

Всё ниже Warning будет отфильтровано. В production обычно нужно Warning или Error; во время разработки Debug более полезно.
