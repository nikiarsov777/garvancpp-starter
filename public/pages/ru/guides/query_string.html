Параметры URL

Всё после ? в URL парсится автоматически. Доступ через req.url_params.

Основное использование

CROW_ROUTE(app, "/search")([](const crow::request &req) {
    const char *q = req.url_params.get("q");
    if (!q) return crow::response(400, "missing q");
    return crow::response("you searched for: " + std::string(q));
});

get() возвращает const char* или nullptr когда ключ отсутствует — всегда проверяйте перед разыменованием.

Множественные значения

Списки пишутся как ?tag=a&tag=b:

auto tags = req.url_params.get_list("tag");
for (const auto &t : tags) CROW_LOG_INFO << "tag: " << t;

Для application/x-www-form-urlencoded тел (типично для HTML форм) вызовите req.get_body_params() — API идентичен.
