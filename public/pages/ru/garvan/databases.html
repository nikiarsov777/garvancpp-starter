Драйверы БД

Garvan поддерживает пять backend-ов "из коробки". Переключение между ними — вопрос изменения DATABASE_TYPE в .env — тот же model/controller/service код продолжает работать.

MySQL

Backed by mysqlcppconn. Опции подключения живут в DATABASE_URL:

DATABASE_TYPE=mysql
DATABASE_URL="mysql://user:pass@127.0.0.1:3306/dbname"

PostgreSQL

Backed by libpqxx. Поддерживает SSL через ?sslmode=require.

DATABASE_TYPE=postgres
DATABASE_URL="postgres://user:pass@127.0.0.1:5432/dbname?sslmode=disable"

MongoDB

Backed by mongocxx. Запросы компилируются в commands, а не SQL.

DATABASE_TYPE=mongodb
DATABASE_URL="mongodb://user:pass@127.0.0.1:27017/dbname"

MonetDB

Backed by libmapi. Полезно для analytical workloads на том же model layer.

DATABASE_TYPE=monetdb
DATABASE_URL="monetdb://user:pass@127.0.0.1:50000/dbname"

SQLite

Backed by libsqlite3. Отлично для development и small deployments.

DATABASE_TYPE=sqlite
DATABASE_URL="sqlite:db/database.sqlite3"
