Утилиты

Три небольших utility класса живут под vendors/Garvan/include/tools/. Встретите их при написании controllers и services.

Helper

Класс Helper — база обоих BaseContoller и BaseService. Предоставляет convenience методы, которые не подходят никуда ещё — форматирование дат, генерация slug, построение response.

#include "tools/Helper.h"

std::string slug = Helper::slug("Hello, World!"); // "hello-world"

JsonValue

Обёртка вокруг crow::json::wvalue с helper-ами для nested объектов и массивов. Используйте как return type для service и controller методов:

#include "tools/JsonValue.h"
using json = JsonValue;

json out;
out["status"] = "ok";
out["data"]   = json::Array();
out["data"].append({ {"id", 1}, {"name", "Ada"} });
return out;
