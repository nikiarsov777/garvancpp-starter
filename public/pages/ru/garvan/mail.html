Почта (SMTP)

Starter поставляется с одним реальным, отправляющим job: AppJobs::SendTestMail. Его handle() (app/jobs/SendTestMail.cpp:58) открывает SMTP-сессию с libcurl, строит RFC 822 сообщение с HTML телом, аутентифицируется, отправляет и логирует результат. Всё управляется блоком MAIL_* в .env.

Конфигурация MAIL_*

MAIL_DRIVER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=465
MAIL_USERNAME="user@example.com"
MAIL_PASSWORD="app-password"
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="user@example.com"
MAIL_FROM_NAME="Your App"
MAIL_AUTHENTICATION=plain
КлючНазначение
MAIL_HOST, MAIL_PORTSMTP endpoint.
MAIL_USERNAME, MAIL_PASSWORDУчётные данные (libcurl auto-negotiate AUTH механизм).
MAIL_ENCRYPTIONtls, ssl или smtps. ssl/smtps форсируют implicit TLS независимо от порта.
MAIL_FROM_ADDRESS, MAIL_FROM_NAMEEnvelope sender + display name в From:.
MAIL_AUTHENTICATIONИнформационно; libcurl auto-negotiate.

Значения могут быть в "..."; job снимает окружающие кавычки перед использованием.

Порты и encryption

  • 465 → implicit TLS (smtps://). Handshake до SMTP banner.
  • 587 → STARTTLS. Job использует smtp:// и форсирует TLS через CURLUSESSL_ALL.
  • Любой другой порт с MAIL_ENCRYPTION=ssl или smtps → форсированный implicit TLS.

HTML содержимое

Header RFC 822 фиксирован на Content-Type: text/html; charset=UTF-8 с 8-bit CTE, так что поле body может содержать произвольный HTML включая UTF-8:

curl "http://localhost:9090/api/jobs/send-mail?to=you@x.com&subject=Hi&body=<h1>Hello</h1><p><b>Bold</b></p>"

Debug SMTP-диалога

Если отправка проходит по мнению libcurl, но письмо не попадает в inbox (spam, greylist, тихое отклонение), временно включите verbose:

// app/jobs/SendTestMail.cpp
curl_easy_setopt(curl, CURLOPT_VERBOSE, 1L);   // смените 0L на 1L

Rebuild, restart, повторите. Получите полный TLS handshake плюс SMTP-диалог на stdout сервера — EHLO, AUTH, MAIL FROM, RCPT TO, DATA и финальный 250 2.0.0 Ok: queued as ....

Не commit-ьте изменение

Verbose SMTP логи утекают sensitive headers и вредят производительности. Верните на 0L перед commit.

Примеры provider-ов

Gmail (app password, port 465):

MAIL_HOST=smtp.gmail.com
MAIL_PORT=465
MAIL_USERNAME=you@gmail.com
MAIL_PASSWORD=xxxx-xxxx-xxxx-xxxx    # app password, не пароль аккаунта
MAIL_ENCRYPTION=ssl
MAIL_FROM_ADDRESS=you@gmail.com

SendGrid (API relay, port 587 STARTTLS):

MAIL_HOST=smtp.sendgrid.net
MAIL_PORT=587
MAIL_USERNAME=apikey
MAIL_PASSWORD=SG.xxxxxxxxxxxxxxxxxxxxxxxx
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=you@yourdomain.com

Custom SMTP (port 465):

MAIL_HOST=mail.your-host.com
MAIL_PORT=465
MAIL_USERNAME=info@yourdomain.com
MAIL_PASSWORD=your-mailbox-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=info@yourdomain.com
MAIL_FROM_NAME="Your Brand"
