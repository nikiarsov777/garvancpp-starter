Контроллеры

Контроллер связывает HTTP routes с data layer. Каждый наследует Garvan::BaseContoller и выставляет пять REST действий, которые вы бы ожидали.

BaseController

Базовый класс объявляет небольшой контракт:

class BaseContoller : public Helper
{
public:
    virtual json index() = 0;          // GET /resource
    json         create(json model);   // POST /resource
    json         read(string id);      // GET /resource/:id
    json         update(json model);   // PUT /resource/:id
    void         erease();             // DELETE /resource/:id
    json         getById(string id);
};

Только index() pure-virtual — остальные имеют default реализацию, которую можно override для конкретного ресурса.

REST действия

Типичный resource controller:

// app/controllers/api/PostController.h
#pragma once
#include "controller/BaseContoller.h"
#include "../../services/PostService.h"

class PostController : public Garvan::BaseContoller
{
public:
    json index() override {
        PostService svc;
        return svc.index();
    }
};

Свяжите его с route в routes/ApiRoutes.cpp:

CROW_ROUTE(app, "/api/posts")([] {
    PostController c;
    return jsonresponse{ c.index() };
});
