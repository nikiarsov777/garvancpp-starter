Конфигурация .env

Garvan загружает runtime конфигурацию из файла .env в корне проекта. Всё что можно поместить в shell environment, можно поместить и сюда — с одним исключением: variable interpolation работает внутри самого файла, так что можно составить database URL из его частей.

Загрузка файла

Файл читается автоматически при старте app. Каждая строка — KEY=VALUE; строки начинающиеся с # — комментарии. Рабочий пример из starter:

DATABASE_TYPE=postgres
DATABASE_NAME=dbname
DATABASE_USER=dbuser
DATABASE_PASSWORD=password
DATABASE_HOST=127.0.0.1
DATABASE_PORT=5432
DATABASE_SSL_MODE=disable

DATABASE_URL="$DATABASE_TYPE://$DATABASE_USER:$DATABASE_PASSWORD@$DATABASE_HOST:$DATABASE_PORT/$DATABASE_NAME?sslmode=$DATABASE_SSL_MODE"

Часто используемые переменные

  • DATABASE_TYPE — один из postgres, mysql, sqlite, mongodb, monetdb.
  • DATABASE_URL — полный connection URL. Query builder использует его если он есть.
  • APP_PORT — HTTP порт; по умолчанию 9090.
  • APP_ENV — development или production — контролирует уровень логирования по умолчанию.
Внимание

Никогда не commit-ьте .env в систему контроля версий — только пример (.env.example). Добавьте .env в .gitignore.
