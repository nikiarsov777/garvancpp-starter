Модели

Модель представляет одну таблицу БД. Она несёт метаданные (имя таблицы, primary key, колонки) и наследует query-builder методы от ORM::OModel.

BaseModel

Разместите модели под app/models/. Минимальная модель:

// app/models/Post.h
#pragma once
#include "orm/omodel.h"

class Post : public ORM::OModel
{
public:
    Post() {
        table          = "posts";
        primaryKey     = "id";
        public_columns  = {"id", "title", "body", "user_id", "created_at"};
        private_columns = {};
    }
};

Связи

Builder предоставляет четыре relation helper-а, которые OModel наследует:

  • hasOne(model, foreignKey, localKey)
  • hasMany(model, foreignKey, ownerKey)
  • belongsTo(model, foreignKey, ownerKey)
  • belongsToMany(model, pivotTable, foreignKey, ownerKey)

Каждый из них планирует join, который resolve-ится при вызове get(). Они зеркалируют relation API, который вы можете знать из Laravel.

User u;
auto posts = u.find(42).hasMany(Post{}, "user_id", "id").get();
