Kalpasan CLI

kalpasan — компаньон командной строки проекта. Скаффолдит модели, контроллеры и сервисы, запускает миграции и seeder-ы, стартует development сервер с file watching.

Установка

Binary находится в vendors/Garvan/kalpasan. Symlink в корне проекта делает вызов удобным:

ln -s vendors/Garvan/kalpasan kalpasan
./kalpasan --help

Скаффолдинг и DB команды

./kalpasan make:model User           # скаффолд app/models/User.{h,cpp}
./kalpasan make:controller User      # скаффолд app/controllers/UserController.{h,cpp}
./kalpasan make:service User         # скаффолд app/services/UserService.{h,cpp}
./kalpasan make:migration create_users

./kalpasan db:migrate                # делегирует garvan-migrate up
./kalpasan db:rollback               # делегирует garvan-migrate down
./kalpasan db:seed                   # запускает файлы в db/seeders/

./kalpasan serve --watch             # rebuild + restart при изменении .cpp/.h

Все команды уважают активный .env, так что работают с правильной БД.

Runtime verbs (jobs, events, config)

Эти verbs общаются с работающим приложением по HTTP (libcurl). Читают KALPASAN_ADMIN_URL (default http://127.0.0.1:9090) и KALPASAN_ADMIN_TOKEN из .env, затем хитают bearer-guarded admin endpoint-ы в routes/AdminRoute.cpp.

./kalpasan job:list                                # GET /api/admin/jobs
./kalpasan job:dispatch SendTestMail \              # POST /api/admin/jobs/dispatch
    --field to=you@x.com \
    --field subject="Hi" \
    --field body="<h1>Hello</h1>"

./kalpasan event:list                              # GET /api/admin/events
./kalpasan event:fire UserRegistered \             # POST /api/admin/events/fire
    --field id=42 \
    --field email=you@x.com \
    --field name="Ada"

./kalpasan route:list                              # печать HTTP routes
./kalpasan config:show                             # dump .env
./kalpasan config:get MAIL_HOST                    # чтение одного ключа
./kalpasan config:set MAIL_HOST smtp.new.com       # перезапись одного ключа
./kalpasan config:key:generate                     # новый APP_KEY (base64 32-byte)
Admin auth guard

AdminRoute отклоняет запрос если не выполняются три условия: KALPASAN_ADMIN_TOKEN непустой в .env, запрос идёт с loopback (127.0.0.1 или ::1), header Authorization: Bearer <token> совпадает. Иначе возвращается JSON error со статусом 401 / 403 / 503 (см. routes/AdminRoute.cpp:55-82).
