ORM / Query Builder

Data layer Garvan состоит из двух частей. Builder генерирует parameterized statements через per-database Grammar, затем запускает их через DbClient. OModel — базовый класс, который ваши model объекты наследуют чтобы выставить эти builder методы напрямую.

Builder

Builder использует fluent API. Каждый вызов возвращает builder так что можно chain-ить условия:

Builder qb(dbClient, grammar, "users",
           /*public*/{"id","name","email"},
           /*private*/{"password"});

auto rows = qb
    .where("active", "=", "1")
    ->where("role", "=", "admin")
    ->get();

Запрос параметризован end-to-end — user-supplied значения проходят через native PreparedStatement binding, а не через string concatenation. SQL injection здесь невозможен.

Другие shortcuts: first(), firstOrFail(), find(id), findOrFail(id), плюс insert(json), update(json) и remove().

OModel

Модели наследуют ORM::OModel и объявляют имя таблицы плюс списки колонок:

class User : public ORM::OModel
{
public:
    User() {
        table          = "users";
        primaryKey     = "id";
        public_columns  = {"id", "name", "email"};
        private_columns = {"password"};
    }
};

Grammar-ы для каждой БД

Каждый driver предоставляет подкласс Grammar, который знает как emit-ить правильный диалект:

  • PostgresGrammar
  • MysqlGrammar
  • SqliteGrammar
  • MonetdbGrammar
  • MongoGrammar — производит Mongo commands, а не SQL.

Правильный grammar выбирается автоматически из DATABASE_TYPE. Обычно эти классы вы напрямую не трогаете.
