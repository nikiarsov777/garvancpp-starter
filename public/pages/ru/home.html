Garvan C++

Быстрый, batteries-included C++23 веб-фреймворк. Garvan расширяет Crow ORM-ом, миграциями, event bus и job queue с реальным SMTP mail job, слоем model/controller/service и CLI kalpasan — чтобы вы могли доставлять HTTP, WebSocket и background работу, не покидая C++.

Работающее приложение за 8 строк

Определите route, верните строку, запустите app. Garvan не мешает.

#include "crow.h"

int main()
{
    crow::SimpleApp app;

    CROW_ROUTE(app, "/")([]{
        return "Hello from Garvan!";
    });

    app.port(9090).multithreaded().run();
}
CROW_ROUTE(app, "/api/users/<int>")
([](int id) {
    crow::json::wvalue user;
    user["id"]    = id;
    user["name"]  = "Ada";
    user["email"] = "ada@example.com";
    return user;
});

JSON, легко

Верните crow::json::wvalue из handler-а и Garvan установит правильный Content-Type за вас. Собственный JsonValue Garvan оборачивает те же примитивы для использования внутри сервисов и моделей.

Знакомый ORM

Fluent query builder пишет SQL для любого из поддерживаемых backend. Модели наследуют OModel и предоставляют find(), where() и связи.

auto users = db.table("users")
    .where("active", "=", 1)
    .order_by("created_at", "desc")
    .limit(20)
    .get();
