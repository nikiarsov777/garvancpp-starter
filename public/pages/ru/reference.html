Справочник API

Эта страница ссылается на сгенерированный справочник API для Garvan и Crow. Фреймворк на C++23 (GCC 14+ / Clang 18+). Справочник генерируется Doxygen из комментариев в header-ах исходного кода.

О справочнике

Справочник покрывает два слоя:

  • Garvan — базовые классы model/controller/service, ORM builder, migration runner и утилиты под vendors/Garvan/include/.
  • Crow — подлежащий HTTP сервер, router, JSON, mustache, multipart и websocket подсистемы.

Пространства имён

  • Garvan — классы фреймворка (BaseContoller, BaseService, Builder, Migration, MigrationRunner).
  • ORM — база OModel и связанные типы.
  • crow — всё из upstream Crow: SimpleApp, App<...>, request, response, json::rvalue, json::wvalue, mustache::template_t.
Статус

Doxygen вывод пока не подключён к этому сайту. До этого — обращайтесь напрямую к header-ам в vendors/Garvan/include/ и vendors/Garvan/crow/.
