# Project BGCHESS SITE

## 🚀 Технологичен Стек (Tech Stack)
* **Frontend:** C++ (Garvan C++ фреймуърк)
* **Backend:** C++ (Garvan C++ фреймуърк)
* **Миграции:** kalpasan CLI
* **ORM:** Garvan ORM  

* **Ползвай винаги модели** class UserMonet :  public BaseModel
## 🛠️ Команди за Разработка (Build & Test Commands)
* **Компилиране на C++:** `./make.sh`
* **Стартиране на приложението:** `../start.sh`
* **Пускане на C++ тестове:** `cd build && ctest --output-on-failure`
* **Изпълнение на миграции:** `kalpasan migrate`
* **Нова миграция (създаване):** `kalpasan new <име_на_миграция>`
